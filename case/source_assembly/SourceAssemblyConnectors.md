# Optional original-source connector startup

`SourceAssemblyBindings::Prepare` requires an explicit `SpotweldDeclaration`
when the authenticated source contains internal spotwelds. An unused declaration
also rejects. The named source adapter resolves the supplied blank-card subset;
TL `type25::Model` owns references and endpoint M/J, and `NodalMassBinding`
combines those contributions with the unchanged complete shell binding.

`coefficients(node)` exposes shell, connector, and authoritative total values.
Connector J is never added to the shell physical/drilling diagnostic channels.
The original seven-part package has959 shells,1093 nodes, six rigid groups and
one internal weld2101297 with endpoints2181504/2204838. Its0.001kg and1e-8kg m²
property split equally across the two ordinary endpoints. The finite-offset
spring must be attached to the same owner before this startup composition can
be used for dynamics; preparing these values alone grants no stepping authority.

The first connector scope excludes rigid-group endpoints. Source startup checks
the complete active group membership; the resident TL contributor also checks
the actual immutable owner membership. Group M/J and generated-primary ledgers
therefore remain unchanged. Initial wall-penalty kinetic bounds use total
ordinary-node mass and each native aggregate once.

The shell-only path retains its original coefficients and allocates no connector
model or combined nodal array. Native source arrays are immutable owned handles.
Failures at any startup stage cannot replace a previously retained composition.
