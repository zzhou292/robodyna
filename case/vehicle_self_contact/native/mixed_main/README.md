# Post-GAPM mixed main source

This immutable source composes actual mixed sides and matching corrected/global
gap operand handles. It preserves every raw origin in `mixed().initial()` and
keeps physical support ownership separate. Original reader raw8 coordinates,
whole physical shell support lookup, source-order certificates and prepared
post-UPDMAT material slots supply all arithmetic. No source-sized captured array
or topology census value enters production.

Each primary first receives the source-selected solid pair and its signed reader
geometry/coefficient. Effective IC1 may permute only the primary; IC>=2 never
computes a hypothetical DDS. INCOQ3 then selects the actual shell owner and the
native MAX overlay. Only a real encoded shell partner receives raw STC. Internal
count/erosion is recorded before shell replacement. Final negative K remains
negative and is counted after all overrides; no face is removed or repaired.

The admitted single S1 PART surface has no S2 or added-node clause. I25SURFI's
first four-word encounter supplies MSR; I25SORS subsequently sorts NSV by positive
external NID. Initial source certificates preserve the consumed node-word order,
including groups with identical nodes but multiple raw owners. Swapping origins
within such a group cannot change either roster. The native source references
are fixed-main-startup/native/original/i25surfi.F520–589 and inint3.F1856–1858,
with pinned i25sors.F71–100. No roster is derived from the final support owner.

Complete source_gaps reduction is reused without changing its math: physical
shell maxima, primary shell mask, beam/spring additions for secondary fields,
separate main field with role-zero clearing. Primary permutation leaves each
mask node set unchanged. ITHK25=0/IGAP0=0 makes neighbor/reference fields
unconsumed; this does not assert that NEIGH/NORM have already run. Main scalar
GAPM length is a separately masked diagnostic, not a contact clearance.

The original physical domain remains immutable here. A final combined vehicle
and finite-wall Starter wrapper must authenticate the real DomainEmbedding,
append its disjoint source suffix before the one topology build and preserve
original self-interface faces/NSV. This handle never forges node_count or a
combined owner. Scalar search/GAPMIN controls, initial history/removal, and
runtime physical/erosion admission remain separate.

`retained_bytes` reports current retained input/output payload using owner-side
capacities and arena extents; `prior_construction_peak` preserves earlier
reservations. No construction scratch is silently treated as retained payload
and no shared backing is subtracted without exact private source identity.
Whole-source execution stays under the existing10GiB guard after a measured
forecast. The small native overlay independently executes original I25GAPM
shell MAX and partner writes on original native signed/internal scalar output.

Gap phase is explicitly pre-BUC. I25BUC_VOX1 can subsequently replace corner1
for solid/coating roles with min(maximum edge length, prior corner1), and derives
EDGE_L2/LEDGMAX. The initializer owns that later source phase and must carry its
finalized gap state into Engine binding. It must not blindly reuse this immutable
pre-BUC array. The separate geometry solid_length is never substituted for
