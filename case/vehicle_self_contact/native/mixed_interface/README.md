# Mixed initial interface source

`MixedInterfaceSource` borrows one immutable `InitialSurfaceSource` and retains its
shared complete physical context. It prepares only native IN24 classification,
I25SURFI tagging/filtering, and SH2 shell sides. `G = P + shell_primary_count`;
solid faces have no fabricated partners. Existing source classes and legacy
startup profiles are unchanged.

The complete selected-shell membership certificate reuses `coated::Classify`.
Each selected shell must have zero or one physical solid match, and the numerical
IN24 result must agree in role and unique solid identity. Multiple physical
matches return `NeedsNativeReaderOrder`; no representative first-solid order is
promoted to source authority. The actual 741 count belongs only to qualification.
Every initial raw origin and prefilter solid tag remains retained. Equal-node
origin groups use the already-qualified initial consumed-word certificate;
`PrimaryOrigin::MultipleOrigins` means parent ID/local-face are unavailable, not
that any owner was deleted or chosen. Contact-primary ordinal/global ID is the
contact identity. A unique IN24 membership witness is not IELEM_M support.

The two retained output arenas share one sequential scratch arena. Forecasts
include the complete incoming source reservation, source packing, role and
incidence workspaces, public interface arena ceilings, count-only sides upper
bounds, digests and census. Exact interface preflight uses real borrowed tables;
no invented descriptor pointers are used. The new cap is 9.5 GiB, and the actual
qualification also admits 128 MiB external overhead under the unchanged 10 GiB RSS
limit. These are conservative reservations, not claimed RSS measurements.

The census reads the same ledger/domain, real rigid binding and source-resolved
shell failure policies. Tied slave declarations are sorted unique by original
NID (`tied_shell/GeometryCensus.cpp`, canonical unique node table then sort); the
consumer checks that retained guarantee before binary lookup. Such candidates
are not finalized CIN. No second physical source or owner is constructed.

The next native phase must supply genuine post-I25GAPM support/internal mappings,
main/secondary gaps and coefficients, including final IDEL_SOLID normalization.
Only then can mixed neighbors/normals and runtime admission be composed. API-zero
neighbor fields in the sides result are explicitly unavailable observations.
No initial contact history, clock, failure-event handling or runtime receipt is
created here.

Qualification reuses the complete independently extracted native IN24/filter/SH2
oracle and existing source fixtures. Small tests cover ordinary/coated/reversed
Q4/T3, solid-only and repeated raw8 origins, genuinely order-sensitive ambiguous
solid membership, forged source identity/role/tag rejection and digest identity.
The explicit full-source fixture builds the initial handle once, checks the exact
inclusive cap, preserves every origin, and emits bounded mass/rigid/tied/failure
census fields alongside the stage result. Production consumers have no native
oracle, Fortran or GTest linkage.
