# Original selected-shell topology assessment

The public API accepts an authenticated `OriginalSelection` and retains its
shared `CanonicalSource` for one synchronous assessment. It keeps every canonical
node and every retained original selected shell parent in canonical record order.
The old centered-parent/physical contact adapter is not involved. Non-shell parts,
solids and beams remain listed as unassessed source dispositions.

Canonical Float64 positions are untransformed SI. TL receives `Coordinates::Si`
and the source-declared unit scale, then applies its existing native working-length
conversion. Neither raw source-decimal double identity nor original full native
main order is claimed. The only TL call is complete general `BuildStarter`;
there is no row deletion/retry, physical state, GPU job or returned Snapshot.
IRR11 warning count/first expanded main and edge remain source-bound. A rejection
has no topology digest or partial geometry result; it retains its exact available
source EID/PID/row/line/NID diagnostic.

`Preflight` reports compiled sizeof/TL forecasts and conservative application
reservations. Complete decoded row/index/line temporaries end before TL allocation;
TL scratch ends before the output digest. The public source reservation remains
charged even if its authentication happened earlier. These values are not RSS.

Digests cover meaningful typed fields only, never pointers or struct padding.
Each field's exact typed little-endian words are encoded in fixed65,536-word
chunks using existing array I/O and SHA-256. A field hash binds name, dtype,
shape, chunk size/count and ordered chunk hashes. The root binds schema, source
input hash and ordered field descriptors/hashes. Counts/policy/origin and all
Starter float32 words (as explicit UInt32 bits) are covered. This structured
root is not a flat output-file SHA. No complete output duplicate is constructed.

The eight small value/digest groups are the first owning gate. The optional
`native_topology_assessment_actual` executable is not automatically registered
as a source-sized CTest. Invoke it only through the existing
`modelio/self_contact/tests/actual_fixture.py` launcher, with explicit canonical
root/scope and either named test filter. `ROBO_NATIVE_TOPOLOGY_OUTPUT` must name
an absent directory. Run the forecast test first, inspect its concrete budget,
then launch the whole-source assessment in a separate directory under the
serialized workstation guard. Every failed attempt and receipt is preserved.
A passed assessment test with `output_complete=false` reports a diagnosed source
rejection; it is not geometry or simulation acceptance.

No source-sized run, physical source admission or vehicle qualification follows
from these source files alone. Numerical startup and the current-normal policy
are qualified by TL; actual app/source-sized gates require their own evidence.
