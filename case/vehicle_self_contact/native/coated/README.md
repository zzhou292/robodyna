# Retained V5 coating source assessment

This is a source-only host assessment of the existing immutable V5 physical
model. It retains all 349,645 physical shell parents and uses all 4,980 retained
physical solids for classification. Only the 337,092 original-contact-selected
shells enter the final native surface order and one coated BuildStarter call.
No omitted original solid supplies a coating role. It adds no physical owner,
clock, source pruning, force law or runtime admission.

The declared native solid reader phase is explicit. H8 retains all eight slots
and applies the existing native CHECKVOLUME_8N orientation branch on original
working coordinates. V5's declared PENTA6 expands six source nodes to
[a,b,c,a,d,e,f,d] before INITIA. Later S6Z active-slot reorientation and untouched
raw slots4/8 belong to coefficient scatter, not this contact reader packet.
The matched selected CPU declaration must use the same named V5 PENTA6 choice;
original collapsed-BRICK/native full-case equivalence is not claimed.

Source-native coordinates reuse the existing bounded *NODE routine, including
original line/NID/blank/code checks and exact native×length equality with both
canonical and physical SI bits. The shared tied-source consumer and old topology
digests remain owning regressions. Original 64-bit identities are checked for
positive native-int representability before case-declared ITAB use. Physical
indices preserve increasing NIDs; six-word surface keys are unsigned, including
negative role words, with original stable tie order. This profile explicitly
selects a single surface with IMBIN0. Duplicate surface keys reject; they do not
silently remove a physical or contact parent.

Complete membership uses node-to-solid incidence, preserving raw repeats for
SEG_INS while visiting a candidate solid once per source node. Multiple matches
are counted and leave those role rows unresolved until genuine native incidence
order is supplied. Every physical shell remains in the report and input digest.
Physical-role completeness and selected-contact readiness are separate: an
unresolved non-contact row does not block the selected surface; any unresolved
selected row prevents ordering and the topology call. Failure is never
retried with deleted geometry. Role determinants are native-observed only for
successful unique matches; unused zero fields are API-defined digest storage.

Qualification is separate from production. tests/NativeOracle and tests/native
compile original reader/IN24/MY_ORDERS routines. Expected startup packets and
roles do not call production helpers. Small native/value tests run first, along
with existing tied-coordinate and topology-digest suites. Optional actual tests
reuse the existing complete authenticated physical-model fixture. They are not
automatic CTests: each requires a fresh create-only output directory, complete
source pins, measured forecast and the serialized guarded execution lane.

The previous original-solid CSV's V5-PID filter gives 741 contact-shell matches
as a cross-check only. The actual test independently derives both full-physical
and contact-selected counts from the prepared 4,980-solid model. No expected role
or observed normal is a shipping input. Source-wide execution and numerical
qualification remain pending until their frozen receipts pass.
