# Independent reader, classification and ordering reference

Pinned OpenRadioss a62b source is qualification-only. Production never calls these
routines. The generator verifies SHA-256 and Git blob identity for all six donors.
It reuses TL's existing whole-routine/constants extractor.

- Reader: exact HM_READ_SOLID complete H8 volume-correction block and distinct
  explicit PENTA6 expansion, after valid IDs have been resolved to internal nodes.
  Original CHECKVOLUME functions are compiled whole. This is not the separate
  six-node BRICK reader branch or later S6Z mechanics orientation.
- Classification: complete original IN24COQ_SOL3 and SEG_INS. Incoming Q4/T3 types
  are supplied as 3/7. The bounded wrapper supplies eight-slot solids and an
  explicit incident-solid order; unselected higher-order families are absent.
  Repeated geometric slots remain; a repeated same-solid CSR visit is unnecessary
  to observe its first match. The wrapper proves neither full-case incidence order
  nor the original importer. Production retains multi-match ambiguity explicitly.
- Ordering: exact I25SURFI key-normalization and six-word MY_ORDERS call, backed by
  the original C sorter. Supplied directed shell connectivity and raw roles use
  single-interface membership zero. The numerical observation returns the whole
  sorted permutation; production rejects duplicate keys pending source handling.

The COMMON-backed reference is serial and non-reentrant. All references are
bounded to 1024 nodes and 256 shell/solid packets, run serially,
and retain explicit native working coordinates. No production numeric helper is
used to generate expected reader slots, roles or order. Root owns this oracle
subtree and NativeOracle.h/cpp; the source author owns NativeTest.cpp and runtime
source wiring. First owning compiler/native tests are still required.
