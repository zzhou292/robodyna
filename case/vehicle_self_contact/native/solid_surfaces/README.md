initial clause result, before I25SURFI classification/filter/SH2. It cannot serve
as a contact runtime source. Main K/gaps, mechanical support/removal owner,
current normals, failure/erosion and physical publication remain separate.
Corrected nodal K is never read as geometry or main K.

The existing authenticated Coated PrepareInputs is reused unchanged. Node order
and native coordinate/SI association remain source-proved; H8 and explicit PENTA
raw8 are the earlier reader packet. Full physical Q4/T3 lookup context stays
present even when a part is not contact-selected. The table traversal used by
the value producer is REPRESENTATIVE, not a native reader ELEM/storage claim.

Only the source-proved single positive PART_ADD child and ordinary LIST profile
is admitted. Multiple native SET clauses merge already-extracted surfaces and
cannot be replaced by flattening their parts. Existing card readers validate
identities and ordinary header tails. The closed fresh conversion context plus
pinned rules establish PART/EXT1, no reversal, NADMESH0 and NUMELTRIA0. See
planning/openradioss-alignment-2026-09-24/ORIGINAL_PART_SURFACE_DEFAULTS.md in the
workspace for the14-donor/40-converter proof. Unknown source scope rejects.

The qualified extraction runs twice using the SAME complete physical tables.
First, its SOLID exterior clause contains exactly the PART-selected solid set
but no selected-shell tag; this exposes only the faces that reach suppression.
No face compacting/cancellation formula is reimplemented. Every matching shell
in the exact Q4/T3 family must have the same selected-membership bit. Since
successful value admission guarantees distinct corners, equal sorted node sets
within that family are precisely native ISHEL==3/4. Ambiguity returns
NeedsNativeReaderOrder without a published source handle.

The actual PART run then preserves all emitted faces. Four-node CREATE sort ties
must have identical authoritative external identity/role/location. An unknown
consumed ELEM tie also returns NeedsNativeReaderOrder. Public faces contain
kind, original EID/PID, raw solid face1..6, original source location and physical
node indices; no representative reader row or buffer ordinal escapes. The
initial output is not I25SURFI deduplication or shell-partner expansion.

Forecast reuses public upstream input/decode partitions, the context's complete
reservation and enforced TL output/scratch ceilings. Real TL preflights run only
after genuine packing and must fit those reservations. Arrays, lookup sorting,
private staging, retained copies and digest workspace are included. No resource
cap, source row or failure law is dropped to produce a Ready result.
