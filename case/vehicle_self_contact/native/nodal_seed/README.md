# Pre-correction vehicle contact coefficients

This source adapter is being authored against qualified TL ordered seed `fa32b673`
and app V5 source `0f7ef145`. It is not yet built or qualified.

The public handle owns a complete ordered contributor roster and the nodal seed /
ASSTIFI values before `STIFINT_ICONTROL`. It preserves original and native IDs,
all eight Penta raw occurrences (including source-initialized zeros), both endpoints
of zero TYPE45 terms, and every physical shell including rigid/noncontact parents.

Preparation calls the source-owned SPRING resolver using authenticated complete
import members. The in-progress resolver is a dependency, not permission to supply
captured or caller-invented native IDs. No full-source numeric result is available
until that dependency is ready and the owning tests pass.

CONTACT_INTERIOR source targets are retained in the result, not silently treated
as Icontrol0. Applying PM107 corrections, coating/solid main coefficients and
beam/spring additions to secondary gaps belongs to later independently qualified
products. This adapter publishes no runtime source or readiness boolean.
