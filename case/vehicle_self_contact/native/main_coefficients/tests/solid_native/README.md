# Independent solid-support source reference

Ten pointer arguments bind complete bounded physical rows to whole pinned
INSOL3D and NORMA1D. Exact BUILD_CNEL solid count/fill blocks retain all eight
raw slots, including repeated PENTA/collapsed-brick slots. Higher-order family
counts are explicit zero for this EightSlot profile. IXS11 is the native source
EID, and the complete emitted-solid flag union is supplied independently.

Numerical statements are unchanged. Routine/module/common boundary names are
private to this serial reference. Two read-only hooks observe IC before and
after TYPE25 flag filtering. The wrapper observes NEL, IELEM_M, every matched
row, the warning branch, primary node order and area. Unwritten channels on
missing support are separately seeded storage observations; they are not
fabricated source values. The production query is never called by the oracle.
Message stubs only count calls and do not influence source branches.

Reference storage is bounded to256 nodes/64 solids. It is not a vehicle source
reader or production library, and supplies no physical/runtime authority.
