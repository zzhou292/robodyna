`TiedSearchFinalized::Prepare` consumes one immutable complete geometric
assessment and retains it through the returned handle. It uses the existing
native value finalizer, preserving original IRECT ranks, stable NSV/MSR maps,
every original slave disposition, unclamped ST/STB and native message actions.
The original selected force-patch status remains on the retained assessment;
an unsuccessful patch is never silently replaced or removed by this stage.

The named source receipt authenticates the complete original contact census
across included files, the exact retained tied contact block and its source
set types/options, and the existing single additive PART-clause packing. Only
the original non-TYPE2 AUTOMATIC_SINGLE_SURFACE and INTERIOR contact kinds are
accepted alongside this one tied contact. Unknown interface roles fail closed.
The receipt describes the first **TYPE2** role, not the first contact of every
kind. Qualified INPOINT yields ordinary IS1=2; unique NSV and fresh serial
LECINT tables yield one registration per slave and zero multiple connections.

This is the fresh physical-coefficient phase before INIEND: ILEV28, IGNORE2,
DSEARCH0, IPROJ1, zero prior connection tables. The native DMIN alias is cleared;
search distances remain diagnostic on the input assessment. No arbitrary M/J
permutation, prepopulated IRUPT, classifier masks or runtime owner is admitted.
Classification remains pending. Accumulation, flush and direct message calls
are distinct; an empty native flush is not a printed warning.

The 512 MiB host forecast charges shared source and assessment backing once,
complete input staging, a bounded source metadata parse and the native value
reservation before allocations. Payload sizes exclude allocator/control-block
overhead and are not process RSS estimates. Existing search driver/device
scratch is no longer retained and is not charged a second time. Source data
and existing V1 outputs are unchanged.

The standalone host target is `robo_dyna_tied_finalization_values_check`.
Enable `ROBO_DYNA_TIED_FINALIZATION_ACTUAL` with explicit
`ROBO_DYNA_TIED_CANONICAL` and `ROBO_DYNA_TIED_SCOPE` to build
`robo_dyna_tied_finalization_actual_check`. That owning test creates the actual
GPU assessment once and compares all original finalization rows and messages
against the complete independently compiled I2TID3 oracle. It requires the
serialized original-source/GPU qualification queue.
