handle. It binds native KINET to every finalized original NSV row and preserves
the CIN/PEN association, five condition fields and interface decoder. The
original contact filename/line/hash and native interface ordinal remain distinct;
no generated source ID is invented. This is a post-KINCHK observation, not
coefficient, constraint-owner or full-starter admission.

The authenticated classification context establishes the consumed exclusions:
all original primitive walls and the wall.key rigid shell assembly are replaced
by the named finite-mesh-wall case policy; source converter roles establish no
RBE2/RBE3/cyclic producer; original joint, rigid PART/extra/group and explicit
PNODE membership is outside the observed slave read-set. Automatically generated
rigid mains occupy new native node indices rather than aliasing an original
slave. Their original source roles remain in the retained context, while their
generated IDs/registration and global hierarchy warning counts stay unspecified.

Complete native KINCHK has no IRUPT argument. Under these exclusions it cannot
alter the observed conditions or ITF decoder and writes KINET from the current
condition field. Possible-conflict flags remain per-node diagnostics. Native
warning 555 from unobserved RBODY hierarchy does not change these fields. The
following INIVCHK initializes rigid/RBE velocities; neither that phase nor
physical M/J and attachment coefficient production is claimed here.

The forecast charges the prior source-context reservation and distinct retained
classification/finalizer payload once, then the new input staging, receipt and
exact native value startup payload. Retired classifier input/native scratch is
not retained. Source reservation remains conservative and is not an RSS claim.
