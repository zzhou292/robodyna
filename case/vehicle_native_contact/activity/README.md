# Selected native V6 activity declaration

`Declaration` is an immutable source value. It never changes the default case
policy, the source contact law, or a runtime mask/history. The owning case must
explicitly opt in and authenticate the actual TYPE45 model through the physical
publication before using these controls.

The original self source resolves to positive I_DEL1, keep-node0 and enabled
post-GAPM solid erosion. The additional mesh wall resolves to I_DEL0 and retains
its own secondary coefficients. These controls come from the existing original
card/default resolver and the actual post-GAPM/wall source declarations.

Coverage compares every executed shell, solid, beam, spring and joint against
its retained source identity and physical endpoint mapping. The declared wall
is a separate environment parent. V6 requires all44 actual TYPE45 joints; an
old38/6 source reduction is rejected. Beam/spring axis nodes, point masses and
bare rigid/CIN membership do not become element support.

The executed model is the already selected `native_v6_raw8_heph_explicit_cin28`
case, not the entire raw archive. The original tire and outside solid/beam rows
are counted explicitly, including whether their endpoints touch retained nodes.
The optional independent roster check compares sorted source-EID digests with
the authenticated existing native case.key; it does not infer exclusion from a
mass ledger or silently add unexecuted elements as static support. Qualification
must retain this comparison before selecting the new runtime profile.

`PreflightPlans` consumes the existing runtime source wrappers and the exact
physical/joint model. Both TL plans must reproduce the declaration's complete
family census. Their output and construction peaks are reported independently.
The case can retire CPU CSR storage after drained device upload; construction
workspace must still be charged while sources and upload staging coexist.

Default CTest runs only six small host tests. Explicitly enabling
`ROBO_DYNA_ACTIVITY_SOURCE_ACTUAL` builds a separate source-only coverage/census
fixture. It reuses OriginalSources::Prepare (including its existing bounded
CUDA tied search), never creates a physical owner, and writes one create-only
report. Run that fixture and the native-roster comparison under the existing
workstation guards; no full simulation is needed for this source qualification.
