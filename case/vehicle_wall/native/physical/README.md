# Combined original vehicle and declared environment coefficients

This first source stage retains the qualified envelope WallSource and genuine
vehicle references, proves the complete original-domain prefix, and constructs
all native coefficient and PART/plain sources on the new full domain. It creates
no VehiclePhysicalModel/VehicleShellBinding impersonation, owner, force history,
CIN witness or final contact arrays. Execution/CIN/joints remain explicit later
constructor stages before a shared owner can exist.

The original physical model and this factory share the same private component
builder. The legacy constructor keeps its original domain/guards and numerical
order. Embedded point-mass and TYPE25 factories require the immutable embedding
certificate; they retain original cards and do not manufacture suffix terms.
The new wall contributes genuine QEPH M/J through the combined shell map.

Original QEPH/T3/QBAT indices remain stable. The environment QEPH is appended to
its family; a separate EnvironmentParent records its actual IDs and shell-local
versus physical-domain indices. Vehicle metrics use WallSource.vehicle_prefix,
never the wall bounds or mass. Native source-length QEPH references are mandatory.

Five small groups exercise exact prefix/suffix/omitted-ID/invalid-span admission
and real QEPH/T3/QBAT append/mapping/coefficient parity. These value fixtures cannot
create the private public source certificate. The optional actual driver uses
the complete authenticated V5, hashes all original named coefficient fields,
occurrences and family mapping before releasing the baseline model, then compares
the combined producer. Whole-model invocations are explicit and guarded; neither
source metadata nor test observations are solver inputs.
