# Native physical contact contribution adapter

This app-private adapter owns an initialized stable-address native Transaction.
The source producer and existing common publisher remain authoritative. Adoption
does not assert parser readiness, broaden the runtime profile or configure a
partial scratch roster. There is no full-V5 factory or finite-wall substitute.

The protocol is accepted material assembly, one native Assemble, complete
physical candidate, native SealCandidate, real scratch receipt and the existing
common commit. The app calls Committed only after successful common publication;
it clears local bookkeeping without a native/owner call. Every error leaves the
caller observation unchanged and revokes local/native scratch. Surrounding case
cleanup still discards material, publication and owner attempts. Accepted state
is never published by this wrapper.

Native observations are separate from M2 diagnostics. Force-base n remains
explicit when the owner publishes n+1. The const transaction view supports
existing accepted-only readback; it exposes no mutable owner or initializer.
The owner/stream/publisher outlive this adapter. Resource reporting keeps actual
native byte categories and bookkeeping payload separate; allocation counts are
not guessed from those bytes.

Current source/runtime profile guards remain unchanged. Two different native
wall/self laws require the closed bounded aggregate participant described in
NATIVE_VEHICLE_CONTRIBUTION_AND_WALL_DESIGN.md. An app loop or shared receipt is
not a substitute. Archive family/profile expansion and physical environment
source composition are separate gates, using the existing vehicle owner and
sampled Chrono archive path.

Owning qualification is `tests/CMakeLists.txt`, requiring an explicit pinned TL
checkout. Two host groups cover adoption/error ownership without a GPU call.
Four CUDA groups reuse the original bounded 18-node owner/material/source
fixture. The wrapped path and direct Transaction path must match exact forces,
stiffness, accepted physical fields and every named contact-history field; an
active common rejection at epoch468 preserves all accepted channels, and retry
reaches the same next state. Additional gates cover phase errors, real roster and
receipt requirements, wrong owner, issuer destruction and publisher detachment.
No tolerance or production profile is changed. These adapter tests inherit the
underlying native numerical qualification; they are not another full-vehicle
source or native-physics authority.

## Ordered native group

Group owns up to the existing TL native-interface capacity in declared order.
It binds the exclusive native roster and exposes actual child receipts only
after every candidate seal succeeds. Observations publish atomically.

Discard revokes native scratch; it cannot undo force additions already made to
the physical assembly. The enclosing dynamics driver must discard the entire
physical attempt on any assembly or seal exception. Committed is an infallible
bookkeeping notification only after successful common physical publication.

The group reports exact device bytes; it does not invent a device allocation
count that the transaction API does not expose.
