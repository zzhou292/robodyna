# Native packing oracle

This test library owns no solver or source registration. The original files
are pinned by revision, SHA-256 and Git blob in `source-manifest.json`.
`generate.py` verifies every file before compiling its complete `MY_ORDERS`
implementation and native `SHELL_SURFACE_BUFFER`, `INPOINT`, `INSURF`, `COUNT3`
routines. The five-word sort block is extracted exactly from
`CREATE_SURFACE_FROM_ELEMENT`; the wrapper exposes its permutation.

Declared context adaptation: native integer common variables are supplied by
`packing_context`; the allocation module owns integer vectors, the reduced
SET type supplies only fields used by `SHELL_SURFACE_BUFFER`, printing is
disabled, and a native warning aborts the test. No geometry, sorting, triangle
normalization or unique-master-node arithmetic is replaced. Explicit Q/T
arrays use caller-supplied native node indices. Their family index is a test
registration, not the original vehicle registration. Unique actual tuples
make that fifth sorting key irrelevant for the admitted app profile.

The packet receives an already unique slave list, executes the exact extracted
`CREATE_NODE_FROM_ELEMENT` small radix/large tagged-scan block, then calls
`INPOINT`. This qualifies ordering;
physical shell/beam/solid incidence remains the immutable declaration's
separate source gate. The full native set-expression/converter/parser and
IKINE classification are not compiled here. Original source IDs are mapped to
monotonic native indices independently in the tests. No app production sorting
helper is used by this oracle.
