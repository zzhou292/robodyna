# Original Yaris structural beam source

`Source::Prepare` authenticates the existing canonical source and original
member, then retains exactly142 original beam records across PIDs2000514,
2000520,2000948,2000950. It uses the existing bounded source-block reader and
shared strict numeric/curve readers. No runtime Python/export fixture is needed.

The immutable value owns four original PART/SECTION/MAT024 declarations,
the46-point curve2100270, all original fixed-column row evidence, and prepared
native beam18 references. Original tonne/mm/s coordinates are reread from
original NODE cards and their scaled binary64 bits must equal canonical SI.
N1/N2 yield146 unique physical endpoints. N3 is retained among147 evidence
nodes and never gains a physical role solely from orientation.

The named profile preserves ELFORM1/QR0/CST1, four circular section points,
original release defaults and LOCAL2. Native declared Ismstr4/storedISMSTR0
and df0/resolved.01 remain distinct from source card fields. The existing
qualified reference and tabulated beam LAW44 preparation are reused. This
source value does not create a Model, coefficient ledger, DOFs, or clock.

`SourceFields`, `SourceCurve` and `OriginalAuthority` are extracted from the
existing vehicle/solid readers; their forwarding callers retain compatibility.
The curve reader now preserves both outputs on a late rejection. Shared
numerical/source-line tests and original solid2412 regression qualify reuse.

Root gate `beam18-source-root-tests-1`: three shared-field/source-line checks,
three actual original beam/source checks and existing solid source/field checks
pass. Every original beam working input is bit-compared with the independently
exported142-beam fixture already qualified against complete native reference
and force routines. Curve values match the existing native-qualified46-point
material fixture. Tests cover source identity, raw/card/blank mutations,
source counts/caps, N3 exclusion and lifetime of owned curves.

Standalone CMake needs explicit Chrono_DIR/ROBO_DYNA_TL_ROOT. Set
ROBO_DYNA_BEAM18_ORIGINAL_TESTS and ROBO_DYNA_VEHICLE_{CANONICAL,SCOPE,BEAM18_FIXTURE}
for original input gates; the fixture is qualification-only. No solver or GPU
runs are part of this source-reader target.
