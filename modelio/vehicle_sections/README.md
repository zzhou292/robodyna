`VehicleSectionResolution` adds a source-only declaration catalog to the immutable
`VehicleSourcePlan`. The historical plan remains V1: 278,301 parents have typed
declarations and 71,344 retain unresolved source blocks. Its geometry and source
backing are shared by value; this module does not create a partial shell binding,
node M/J, native reference, history, owner, contact eligibility or connected load path.

The separate `robo-dyna.vehicle-section-resolution.v1` sidecar authenticates the
original archive/member, canonical manifest, full scope and historical plan. Every
retained parent has its original EID/PID and complete Q4/T3 topology index. These
indices include unresolved slots; they do not authorize an incomplete family.
Existing declarations keep their original values and continuation policy. Unresolved
rows expose no native material or parent input.

The named `openradioss_mat024_positive_fail_constant_all_points_v1` policy resolves
only ordinary ELFORM2/16 NIP3 LAW44 with positive literal FAIL, positive C/P, supplied
VP0 and no other unsupported card options. Pinned OpenRadioss
`a62b27e6baa555d222a580d6218867d0be4d70b5` `convertmats.cxx` maps FAIL to Johnson D1,
IFAIL_SH2 and clears point EPS_MAX. The qualified three-point caller gives the
constant all-points policy. Source seconds resolve the existing 10,000/s filter;
all native tabulated LAW44 declarations, including ordinary FAIL=0 materials,
explicitly use `NativeLastSegment` continuation through the shared native source
adapter. Failure activation is independent of curve continuation. Supplied zero
ETAN on the table branch is retained with its original bits: that converter branch
sets native B to zero. Nonzero table ETAN remains outside this narrow resolution;
legacy readers still require their original blank table ETAN and reject FAIL.

Configure the host checks with `cmake -S modelio/vehicle_sections -B <build>`,
`-DChrono_DIR=<Chrono config>`, `-DROBO_DYNA_TL_ROOT=<TL checkout>` and
`-DROBO_DYNA_FULL_SHELL_RECORD_TESTS=OFF`. Target
`robo_dyna_vehicle_section_fields_check` tests tiny declaration fields; it is not
actual-source acceptance evidence. For the actual owning test target
`robo_dyna_vehicle_section_resolution_check`, add
`-DROBO_DYNA_VEHICLE_SECTION_ACTUAL_TESTS=ON` plus explicit
`ROBO_DYNA_VEHICLE_CANONICAL`, `SCOPE`, `DECLARATIONS` and `RESOLUTION` paths using
the same prefix. Run `ctest --test-dir <build> -R '^vehicle_section_' --output-on-failure`.
The actual fixture tests validate all original rows, independent raw-card numerical
mutations, source/disposition rejection, byte caps and clean retry. No GPU is used.
