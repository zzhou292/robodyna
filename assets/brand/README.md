# Robodyna identity

The primary logo combines a geometric R with a flow curve, representing structural
and fluid simulation in one engine. The exact wordmark is **Robodyna**.

`robodyna-logo-primary.png` is the selected generated asset on an opaque white
background. It was produced with the built-in image-generation tool and copied
without pixel edits; no API/CLI fallback was used. `logo-prompt.txt` records the
final prompt and `generation.json` records file identity.

Earlier transparent concepts were not selected for the repository header. Existing
Chrono attribution and original demonstration logos remain intact.
