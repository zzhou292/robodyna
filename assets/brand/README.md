# Robodyna identity

The primary logo combines a geometric R with a flow curve, representing structural
and fluid simulation in one engine. The exact wordmark is **Robodyna**.

`robodyna-logo-primary.png` is a transparent RGBA PNG. Its empty background and
letter counters have real alpha transparency, so it can sit over documentation
and simulation scenes without a white panel. The native viewer uses an identical
copy at `src/compatibility/chrono/data/logo_robodyna_alpha.png`.

The built-in image-generation tool removed the original white background. The
selected output was copied without pixel edits; no API/CLI fallback was used.
`transparent-prompt.txt` records that edit, `logo-prompt.txt` preserves the original
design prompt, and `generation.json` records the file identity and alpha checks.

Chrono copyright and license notices remain. Dedicated Chrono logo assets are
replaced in the current source tree; original import history and historical
verification evidence remain available.
