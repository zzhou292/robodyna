# LAW90 point qualification

The engine point runs independently of any element, owner or app admission.
Its complete donor is SIGEPS90, with all selected ten-history/three-cursor
updates. Native preparation comes from the already qualified33-field
preparation ABI; direct UPARAM assignments in NativePoint.F are slot packing,
not a second parameter formula. PM1, not current density/PM89, supplies rho0.
The native oracle compiles complete VINTER source and both complete spectral
subroutines from authenticated enclosing SIGEPS33. IRESP0 is selected; the
unused DP symbol is still the complete donor. Only private names change.
The file-descriptor context supplies two output units for unselected removal
messages and has no numerical formula. Native NGL1 is a synthetic oracle
point label, not an original element ID.

The original28-point curve/header/receipt are reused from the owning
`law90_preparation:fixture` target. There is no duplicate source parser, curve
conversion, fixture population or source-object ownership. Existing spectra
and curve implementations remain unchanged. The shared represented-tensor
positive-definite guard is extracted from LAW42 with identical expressions;
its old entry forwards to it, preserving the existing material contract.

New host5 cover virgin/positive-time separation, PM1 density, nonunit ET,
unloading scalar-rate/path updates despite Hys1, carried slot5, tensile cap
before stretch division, actual original rotated320-step history and late
cursor/curve/stretch/arithmetic failure/retry. Native5 add complete independent
original axis/rotated trajectories, nonzero constructor packets, all history
fields and exact cursors, a zero-slope plateau, knots and tension, plus retry
against independently advanced native history. CUDA2 use the same native
original320-step and plateau/knot/cap trajectories, with device-owned late
input/cursor/curve faults, preserved accepted values and successful retry.

Comparison coefficient2e-10 uses current precap/Cauchy stress norm for stress,
current/max path-energy norm for Pa energy histories, and each remaining
quantity's own scale (minimum1). Cursor comparisons are exact. Separate
negative controls reject altered reference density, slot5, and ET. Native
and production arithmetic are never changed to improve comparison scores.
