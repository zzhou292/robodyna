# Contact activity operand qualification

The host tests compare native removal and signed-counter rules with the existing Fortran oracle and test bounded layouts. CUDA tests compare complete coefficient, neighbor, normal-topology, ordered-free-roster and SI arrays against original native discovery/removal operations on an existing complete physical source fixture. They include unselected support, later removal, discard/retry, unchanged content across new snapshot generations, fixed-profile slot reuse, I_DEL0 preservation, malformed activity and exact capacity limits.

CudaValues.cu independently compares the GPU value helpers with source-derived native exposure, multiplicity and signed-counter cases. These numerical coupons do not manufacture physical-owner authority. Real receipt/owner/commit behavior is covered by the snapshot and transaction integration qualifications.

Configure with an explicit qualified TYPE25_ACTIVITY_NATIVE_TEST_ROOT and authenticated TYPE25_ACTIVITY_NATIVE_SOURCE_ROOT; the local Fortran compiler is passed explicitly by the bounded recipe. Build only type25_activity_operands_host and type25_activity_operands_cuda first. Do not run a full vehicle merely to test this component.
