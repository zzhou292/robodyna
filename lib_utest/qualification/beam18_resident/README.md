# Beam18 resident qualification

The host gate checks exact complete arena caps, curve relocation/owned identity,
full result validation, two-endpoint translation/rotation gathering, RHS work,
source-order assembly and atomic late rejection across six force/couple arrays
plus STI/STIR. The owner fixture adds real typed beam coefficients to the existing
complete shell/solid/point/TYPE25 fixture, then rebuilds its PART and plain bodies
from the same V5 ledger. It includes ordinary, PART and plain-rigid beam endpoints.

The CUDA gate uses the real `FENodalState`, CIN transfer/motion and private
publication claim. Loads act on the actual owner. Each prepared beam packet is
compared with the existing independent native beam oracle using those copied
owner fields and independently carried native histories. Eight accepted intervals,
wrong claimant, later-contributor rejection, late cache corruption, complete
accepted readback preservation, discard/retry, exact caps and source/output alias
checks are included. The qualifier's closed coordinator performs one actual
owner commit; it is not an app/full common-publisher admission.

Optional original142 coverage authenticates the existing binary fixture and
material cards through the existing generator, constructs all native/CUDA TT0
packets and destroys the caller's model/domain/curve backing before complete
readback. This is allocation-only source constructor coverage; it does not claim
an owner for the standalone 147-node geometry domain. No copied donor or new
Fortran arithmetic is added: the existing force/reference oracle remains owner.

Root execution (under the workstation guard):

```sh
cmake -S lib_utest/qualification/beam18_resident -B <build> \
  -DBEAM18_RESIDENT_CUDA=ON \
  -DBEAM18_RESIDENT_SOURCE_FIXTURE=<crash-work>/reports/yaris-beam18-geometry-1
cmake --build <build> -j2
ctest --test-dir <build> --output-on-failure
```

Owning targets: `//lib_src/elements/beam18/resident:batch` and
`//lib_utest/qualification/beam18_resident:host`. The standalone CMake gate owns
the independent native/CUDA executable. Re-run affected beam force/model and
plain-rigid source/native/owner targets with their unchanged gates. The actual
full vehicle and common publisher remain separate integration gates.

Author evidence: nine host functions pass with the real V5/PART/plain fixture;
21 production/qualifier C++ and CUDA-shaped syntax units pass. The optional
original142 translation unit also passes C++ syntax using root's already
generated fixture. Source identities pass. No author native, NVCC, CUDA or
Bazel execution is claimed. The 142-parent device arena is 571,520 bytes on this
layout; the declared 372,435-node initial proof is 44,870,848 host bytes, with no
second retained node arena and no per-step allocation.
