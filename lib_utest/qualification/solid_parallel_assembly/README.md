# Parallel solid assembly qualification

Base: TL6bb1cee1. Public Batch API, formulas, family/parent/slot order and common
owner remain unchanged. One immutable CSR enumerates every original occurrence,
including repeated rear H8 slots. Three stream-ordered kernels perform the original
geometry/view precheck, staged per-node force/STI sums, then publication. Only an
integer failure flag uses atomics. Couples and STIR are never written.

Every mathematical/alias/topology failure replays the pinned original serial
traversal on untouched owner arrays, preserving first error and partial failed-trial
writes before the existing owner discard. A CUDA launch/runtime failure poisons the
batch; it never triggers a numerical serial retry. The private source baseline's
four function bodies are pinned by verify_sources.py. No public caller can request
a mode or supply incidence authority.

The original borrowed owner contract requires external arrays disjoint from the
batch's private arena. The range check declines fast execution on a violation;
this is not a promise to reproduce arbitrary self-corruption of control/index memory.
External force/STI aliases, malformed phases, zero nodes, duplicate nonrear slots,
nonfinite inputs and arithmetic overflow do retain the original diagnostic path.

The exact arena forecast includes offsets, occurrence indices and four doubles per
physical node. Existing host upload staging includes that device arena once. There
is no per-step allocation. Output/source alias and cap proofs remain owning gates.

Configure this folder with the same pinned native-donor cache variables used by
extended_solid_resident. It reuses that complete owning CMake project and adds three
host groups, seven CUDA groups and the frozen-body proof; existing native-history,
owner/publication/rollback/cap tests remain required. Run CTest serially under the
normal bounded GPU guard. Also run the new Bazel host target and affected owning
source manifests. No tests were executed by the source author.

The benchmark is deliberately separate from CTest. It obtains five families of
actual caches after eight real existing-fixture owner commits, then copies those
cache values into controlled synthetic parent/node incidence. Each timed call
includes either the exact old serial assembly or all three current kernels plus
control readback and stream completion. Reset, full-array/report bit comparison,
fixture evolution and allocation are outside timing. Every repetition compares all
arrays and report fields; current execution must take no exception fallback.

Run the SAME binary/affinity/guards with SOLID_ASSEMBLY_MODE=serial/current in ABBA
order. Use SOLID_ASSEMBLY_PARENTS_PER_FAMILY=1,64,1000 and matching independently
varied SOLID_ASSEMBLY_NODES (at least 8, at most 524288), with fixed
SOLID_ASSEMBLY_REPEATS. All five families and repeated H8 slots remain present.
Suggested controls: (1,64), (64,4096), (1000,376930); add a dense shared-node case
(1000,64). This is a complete-assembly component benchmark, not Yaris throughput or
proof that the final GPU solver is faster than a matched CPU implementation.
Production promotion requires owning parity, resource admission and measured gain.

The frozen serial numerical body is compiled against the same current typed arena
layout as the parallel path. This isolates assembly execution; it is not an
old-whole-library allocation/throughput comparison. The complete output/report
comparison is fieldwise on every iteration; emitted input and field-bit digests
allow cross-process ABBA corpus checks without timing serialization.
