# Optional CUDA facet-filter integration

Worktree base 17dc plus the qualified standalone 7f3 filter range. Source only until
owning qualification. The public option enable_cuda_facet_filters defaults false.
Disabled execution retains the scalar pipeline and adds only the optional-owner
handle to sizeof(Impl); that fixed overhead is honestly forecast. No optional
O(F+K) arena or device allocation exists when disabled.

One private FacetFilters owner composes the numerical Batch. A compact scene has
accepted/prepared triangles and half-thickness/complete-rigid properties, 160F
bytes on the selectedABI. Batch device payload adds 12K bytes, host readback 4K
plus fixed owner data; existing bounded-arena alignment and typed sizeof drive
all real forecasts. Startup locals are separately counted. Global transaction,
workstation and per-component limits remain in force. Unavailable startup host
arithmetic selects lifetime CPU fallback before any filter CUDA command/allocation;
forecast remains the conservative optional reservation while allocations() reports
actual ownership. Later noncanonical query environments also use the original CPU
path before commands. CUDA errors never trigger successful CPU fallback.

Accepted scene upload occurs once after actual accepted geometry/source checks,
and is reused across both accepted-census passes. Scalar and GPU classifications
feed the same extracted validation/error/compaction body. GPU admission stops
before the first invalid ordinal/parent, so that an earlier numeric-invalid row
still wins over a later malformed row. Per-row numeric errors are consumed at
original ordinals; metadata errors keep the exact original report.

Candidate scene upload occurs once after source/motion/triangle authentication.
The existing serial nonlinear classifier/work counters remain in Candidate.cpp.
Only its ordinary affine-prism call is optional. A private pure helper finds the
next contiguous linear span; it stops before nonlinear, excluded or malformed
rows. The adapter queries that span only when the original loop reaches its first
row. It consumes cached results in that same order and resets the cache at every
stream chunk. It does not speculate across nonlinear work/error boundaries.

Discard and any failure revoke the current scene and all ephemeral borrowed
aliases. Owner/output range checks include numerical batch/control/host/device
storage. Batch calls drain borrowed inputs before return. Source geometry, force,
STI, receipt publication, capacities, clock and policy are not replaced by the
filter module; a filter result is not a physical issuer.

Qualification authored: 4 host value groups; 5 numerical-adapter CUDA groups;
3 actual-owner transaction CUDA groups; 2 additional standalone Batch lifetime
checks. They cover conditional exact forecasts, real disabled/extra cudaMalloc
counts, accepted two-pass force/STI/receipt/state parity, invalid earlier row,
cached-span environment changes, nonlinear work exhaustion, discard/retry and
explicit poisoned CUDA failure. Existing transaction/source/syntax/determinism,
standalone filter parity and affected application gates remain required.

Production app opt-in is a separate later configuration change after qualification.
This source does not integrate the independent exact GPU-native certificate owner.

Independent source review found and closed a device-poison/fenv fallback bug.
The first actual DeviceFailure now remains latched across Discard and is checked
before every environment branch. Initialization/scene/chunk lifetime errors also
precede CPU fallback. Explicit tests cover failed copy, discard, unsupported
rounding, attempted scene/query reentry and restored RN retry. No such operation
may hide a poisoned device behind successful CPU execution.

Author qualification is limited to twelve targeted CXX syntax units and owning
text/source arithmetic proofs. No numerical or GPU test ran during authoring.
The untouched default CPU path's large buffers and allocation count remain the
same; exact current preflight includes its small optional-pointer control delta.
