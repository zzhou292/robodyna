# QBAT private trial storage

The resident batch writes its existing unpublished `BatchResult` fields through
a borrowed output view. The public force/value adapters retain local staging,
reference/material admission and failure-atomic publication. Accepted history
and private trial backing remain distinct; no new array, clock or launch policy
is introduced.

The force-body proof authenticates four exact prior C++ files from69a1d05c and
compares the complete force sequence after a closed list of storage substitutions.
It separately verifies original public identity checks, history validation and
the single changed resident call. Native Fortran donor hashes and tolerances are
unchanged. Older mapped-source receipts retain all prior hashes and frozen
callers, with five explicitly reviewed inherited69 record updates documented.

Three new host groups compare every defined field to the public adapter and
the original native recurrence, including all four removal-point orders and
inactive updates. Two new CUDA groups evolve public/resident histories
independently and test dirty late failure, accepted-state preservation, retry
and same-row rejection. Existing public output-alias/failure preservation,
resident common-owner and mapped CIN/constraint tests remain in the gate.
Comparisons use the existing named `ResultValues` fields, never struct padding.

The initial proof failure was an end-anchor selecting the reset function's
stamp assignment before the numerical body; it is preserved in
`qbat-private-trial-source-1.json`. The subsequent body proof passes. The separate
inherited manifest mismatch receipt records old and qualified69 identities;
no blanket hash refresh or native-source edit was used.

Compiled STACK/REG and actual driver-memory observations are separate from
numerical qualification. Do not infer additive whole-device savings from the
global-memory launch trace. The full owner guard remains unchanged.
