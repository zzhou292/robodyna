# Independent mixed interface source oracle

This serial bounded reference calls complete pinned IN24COQ_SOL3/SEG_INS,
literal I25SURFI source copy/tag/count/fill/filter blocks, original MY_ORDERS,
then full SH2SURF25 from the existing startup oracle. It does not call production
geometry, filtering or expansion. Its18-pointer C ABI is independently marshalled
over256 nodes/256 raw faces/64 rows per physical family.

Exact BUILD_CNEL count/fill blocks retain corner-major raw8 repetitions. The
complete physical context is provided. Higher-order counts are explicitly zero
in the selected low-order profile; raw roles are1/3/7, ILEV1, IMBIN0. BITSET is a
fail-closed unselected-branch stub. Runtime, support, normals and erosion are not
claimed by this reference.

Only read-only observations are inserted: first matched solid at IN24 label500,
the actual native winner when IRECT is written, and the row mapping after each
native filter decision. Supplied input origin metadata is preserved separately;
multiple-origin unavailable IDs and local ordinal metadata are API definitions,
not mechanical owners or unassigned native scratch promoted to authority.

The existing source and startup oracle libraries supply their private modules,
CNEL conventions, shared original C sorter and SH2 routine. Additional includes
use the same C_DOUBLE/constants environment. All bodies and blocks are checked
against exact a62 blobs before generation. Shared Fortran COMMON remains serial
qualification state; separate oracle C++ mutexes do not claim cross-oracle
threaded safety. Consumers must serialize different native reference adapters.
