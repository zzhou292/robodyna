# Enclosing shell output range qualification

The optimization certifies separation only. An intersecting enclosing span must
fall back to the exact old predicate, including its gaps, zero-length boundaries,
source object checks and catalog/failure scan order. No new rejected interval or
cache is introduced.

The oracle consists of the complete341d60f formulation and execution predicates.
Frozen files are authenticated; oracle files differ only in namespace and rooted
includes. generate_oracle.py is the single adapter, and source verification checks
the checked-in oracle text against it. The test does not implement a second alias
algorithm. The current callers reverse exactly to341 after removing their five
enclosing filters; storage, accessors, original Disjoint and footprint sources
remain pinned unchanged.

Ten host GTests cover:
- Checked helper endpoints, inclusive span construction and empty/null/overflow
  output tokens without dereferencing or allocating output memory.
- QEPH/T3/QBAT individually with one and129 parents, and the existing mixed
  six-parent fixture repeated1,22 and65 times. Only EIDs/family indices change;
  geometry/material/section/curve/failure declarations come from existing fixtures.
  This covers inline storage, catalog-only expansion and Q130/T195/catalog390.
- First/middle/last protected bytes, exact ends, zero extents and one-byte crossings
  for every reference, node array, declaration and failure row; external output,
  complete ranges and spans across separate retained allocations.
- Heap source-ID/material-index gaps explicitly accepted by341, while analogous
  inline object gaps retain their original rejection. An envelope intersection
  alone is deliberately insufficient to reject these outputs.
- Binding/catalog copy-on-move, shared expanded backing, independent equivalent
  catalogs and actual failure.catalog versus execution.catalog ownership.
- Real prepared empty rigid execution, existing nonempty PART topology fixture,
  unprepared/missing handles and unchanged external bytes.
