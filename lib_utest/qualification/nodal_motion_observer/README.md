# Complete prepared motion observation

The optional production observer captures the fresh owner's original X once,
then inspects the entire actual active slab. Reactions, rigid and CIN tails stay
in the finite check even when no host field output requests them. Nodal unit
quaternions use the existing shared predicate. Only after those checks do motion
component errors become publishable; finite difference overflow still rejects.
The scalar reduction carries no sum, interpolation, physical state or clock.

CUDA checks reuse the actual ordinary/rigid/CIN owner fixtures and the independent
full snapshot plus host component scan, including accepted-state preservation,
late unrequested-field corruption, rejection priority and exact retry. Deliberate
const-cast writes are qualification-only faults, never product entrypoints.
The owner still grants no candidate acceptance through observation. Host capacity
checks require no GPU. Production target precision remains the existing explicit
nodal flags. No numerical or performance execution is recorded by source readiness.

The app benchmark separately calls its actual old CopyPrepared+ObserveUniformMotion
path and the new complete observation, using a single prepared owner and identical
counts. It measures host elapsed completion, not CUDA event/kernel time, and cannot
establish full-solver or full-vehicle performance.
