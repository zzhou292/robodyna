# Native contact over an active physical prefix

`AllActivePrefix` is an explicit runtime profile. It admits the actual complete
physical ledger and ordinary selected QEPH/T3/QBAT contact parents while all
original material laws continue to run. Source admission requires accepted-owner
response mass and explicitly resolved native ITHK0. Existing IGAP1, IGSTI4 and
ISTIF_MSDT0 numerical guards remain. Unknown update policy stays closed.

The owning transaction initializes `PhysicalActivePrefix` against the actual
publisher and all physical participants before attaching its native history.
A candidate checks that predicate before staging selectors or issuing a receipt.
On failure, the common owner and complete publication discard the attempt.
The mandatory participant prevents a later commit without that check; this
proves the accepted active prefix without duplicating the accepted activity
readback at every interval. Calls are serialized and all borrowed participants
must remain alive, as for the underlying physical owner.

The source mapping uses exact original ordered connectivity for each formulation.
No QBAT material, shell placement, failure strain, force, mass or timestep is
changed by admission. The default no-declared-failure profile retains its old
rejections. Additional scratch is explicitly forecast; no per-step allocation
is introduced. The initial backend reuses validated family activity readbacks;
its full-vehicle cost must be measured and optimized if needed.

Qualification uses synthetic declared contact sources, genuine CIN, solids,
welds, native one-point and four-point material updates, contact-history rollback
and exact force/STI retry. Those coupons do not supply a Yaris startup history.
The real-CIN reference exposed nonzero native TIME_S and pre-removal initial
penetration history. A source-derived initializer remains mandatory before the
full CIN/Yaris source can use this runtime. Mixed solid/coating surface topology,
actual source event/release scope and full source startup remain separate gates.
No runtime-ready full vehicle or performance claim follows from this profile.
