# Owning moving-scene qualification boundary

The first real physical coupon is the original exported18-node8T3 wall/4Q4 patch,
not a prescribed point trajectory. TL alone computes every step, material history,
contact inventory/classification/response and nodal update. Captured source operands
are temporary qualification-only fixtures; the app must use genuine source producers.
The shared app native-H bridge records its actual ≤2ULP prepared-H representation.

Run1,000 real common physical commits at300ns. Physical state at epoch n compares
to native MAINF entry n. Contact row state after commit n+1 compares to native
MAINF return n, tagged by the separate force_base_stamp. Terminal native force
return1000 is not an extra TL physical interval. Exact integer fields, selected
features, ICONT and complete force-packet identities/order are required. The
reference includes impact, persistence, loss and source secondary13 recontact.

Before execution the whole-trajectory limits are fixed at relative2e-8, plus
absolute2e-8mm coordinates/penetration/selection metrics,2e-5mm/s velocity,
2e-5N force/history and2e-3N/mm stiffness. Native sentinel metrics remain exact.
These allow accumulated unit-representation arithmetic and the explicit material
bridge; they do not permit changed discrete transitions or unexplained differences.
Leaf comparisons remain the stricter existing native/CUDA tests. Any discrepancy
is retained and investigated before promotion; tolerances are not silently widened.

The gate also rejects an active-force common commit and retries from identical
accepted nodal/contact fields, rejects full optimized-cap overflow without partial
publication, checks source span/readback alias contracts and publisher-first
lifetime revocation. Raw fixed-node M/J are compared independently to Starter.
A short300us trajectory may reuse its one initial native reference; a genuine
maintenance-driven rebuild requires an additional matched window if not reached.
No GPU speed, adaptive/full-vehicle or final Yaris-video claim follows from this gate.
