# Complete KINCHK supplied-context oracle

The manifest retains the complete pinned OpenRadioss `kinchk.F` at revision
`a62b27e6baa555d222a580d6218867d0be4d70b5`. `KinChk.inc` is the exact complete
first subroutine, source lines 35–1228, including the native unconditional
RETURN and its unreachable older warning tail. No numerical/control statement
is rewritten. The preprocessor maps `my_real` to binary64, as in the existing
standalone classifiers. Complete KININI/KINCOD come from the owning classifier
oracle, whose native files and previous ABI remain unchanged.

The packet supplies bounded original node labels, five condition blocks and the
already computed ITF table. Test-only body columns define supplied native
NPBY/LPBY records, including independent hierarchy/sensor flags; these are not
claimed to be actual vehicle-generated main nodes. Optional wall/RBE2/RBE3/cyclic
nodes exercise excluded native branches. Every extent/index is checked before
native access or output publication. IRUPT is deliberately absent from the
native call.

The shared standalone context gains the KINCHK dimension common block and
message counters. Existing penalty accumulation semantics are unchanged.
Formats/title stubs affect text only. The packet reads the native summary text
to distinguish its possible-conflict decision; it never calls the production
predicate. Full native warning/error counts are packet diagnostics, not original
global vehicle warning claims. The same native library is shared with the
classifier to avoid conflicting Fortran COMMON/module owners.
