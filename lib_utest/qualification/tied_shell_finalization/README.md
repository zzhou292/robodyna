The production value stage consumes complete source-ordered IRECT/NSV/MSR and
selected projections. It publishes immutable stable row maps, original-row
dispositions, unclamped ST/STB and native message actions for the explicitly
supplied serial first TYPE2 level-28 profile. It creates no solver state or
physical coefficient inventory. The app must authenticate this source profile.

Finite S/T outside 1.5 reaches native removal and warning; exact 1.5 remains.
Unmatched rows and warning accumulation/flush/direct calls remain explicit.
Repeated triangle slots are retained. Invalid ranks, nonfinite fields and
resource failures preserve the prior immutable result. The 64 MiB default
budget charges output capacity, scratch and any previous output backing before
borrowed values are read; payload accounting excludes allocator/control blocks.

Configure this directory with `-DTL_TIED_FINALIZATION_NATIVE=ON` for the owning
complete I2TID3 oracle. Targets are `tied_search_finalization_values_test` and
`tied_search_finalization_native_test`; CTest also verifies source identities.
The reusable `tied_search_finalization_oracle` target supplies the same complete
native comparison to original-source app qualification without another wrapper.
