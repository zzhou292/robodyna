# Complete controlled HEPH family values

PrepareReference caches physical and native numeric references/materials.
PrepareInitial/PrepareCandidate write only caller-owned unpublished scratch,
including the actual local native batch-damping trigger. Complete requires the
native batch OR, applies distortion in native units before any SI conversion,
and publishes a typed proposed native material/FHOUR/EINT_DISTOR history.

All material, controlled HG and distortion stages retain native arithmetic.
History is never roundtripped through SI between steps. World inputs/owner clock
and force/STI/work readback remain SI. H24's final raw STI goes to native SCUMU3;
the quarter nodal factor belongs to existing assembly, not this value stage.
This is a numerical family wrapper; no vehicle/profile or physical owner is enabled.
