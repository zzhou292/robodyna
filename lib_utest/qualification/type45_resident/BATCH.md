Six host functions cover native-leaf recurrence, candidate-owned automatic stiffness, source/phase mismatch, late failure and retry, typed slab lifetime, exact caps, complete output alias rejection and authenticated main-context mapping. Existing virgin-constructor tests remain registered.

Three owning CUDA functions use the actual six-family physical owner fixture plus TYPE45: all three joint kinds in SI and millimetre working units over eight accepted intervals, exact force/couple/STIF scatter, independent native startup and recurrent packets driven by actual owner snapshots, late last-joint failure, common rollback/retry, forged capture rejection, exact participant claims and epoch-zero readback. Native history advances only after common acceptance. They retain the previously qualified operation-scale length comparison; no new mechanical formula or tolerance is introduced.

The source/native leaf and owner main-query dependencies were independently qualified before this resident slice. Actual CUDA/native execution of this new composition is root-owned; host-shaped kernel syntax is not a GPU result.

```sh
cmake -S lib_utest/qualification/type45_resident -B BUILD \
  -DCMAKE_BUILD_TYPE=Release -DTL_TYPE45_RESIDENT_NATIVE=ON \
  -DTL_TYPE45_CUDA=ON -DTL_TYPE45_RESIDENT_CUDA=ON
cmake --build BUILD -j2
ctest --test-dir BUILD --output-on-failure
bazel test //lib_utest/qualification/type45_resident:resident_host
bazel build //lib_src/elements/type45/resident:batch //lib_src/elements:shell_batch_publication
```
