# Physical activity snapshot qualification

The snapshot observes one existing physical owner and publication. It captures complete QEPH and T3 parent activity on their owning stream, shares the resulting resident masks across contact consumers and leaves all other removal paths guarded. It does not publish mechanics, delete nodes or change mass.

The owning fixture tests source and token authentication, fresh repeated borrows, aliases, stale receipts after discard/commit/destruction, genuine T3 material removal, exact discard/retry, committed inactive activity and scalar-copy failure atomicity. A device coupon uses actual participant inputs to check invalid and reactivated base flags without modifying physical history. Host tests cover storage limits, overflow, typed reports and preserved unsupported-family obligations.

Run only the two named targets first; this project reuses the existing physical publication fixture. CUDA and build resource limits are supplied by the workspace bounded-run recipe. No full-vehicle acceptance is implied.

TYPE45 massless joints are authenticated against their actual attached model, source ID and complete count. `ValidateType45Source` accepts a shared handle to that exact model and rejects same-size foreign models; null is valid only when the authenticated roster has no joints. The view reports the proven joint count, while TYPE45 remains always active under its existing operator contract. Observer capture generations are separate from any native-contact content generation.
