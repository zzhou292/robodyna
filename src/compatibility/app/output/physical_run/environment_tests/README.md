# Declared fixed environment accepted output

This gate extends the existing complete physical accepted-frame capture. It does
not create another physical owner, native history format, contact law or clock.

`Mapping::Prepare(Source)` retains the actual immutable runtime Source and its
DomainEmbedding. The only new admitted suffix is one declared elastic QEPH and
four physical nodes. Every original canonical shell/node identity and family
index remains unchanged. Original-only APIs still require exact old counts.
Global LAW1 NPT0 parents remain zero-point nonplastic rows; QBAT has four real
plastic points and the existing one-point T3 remains one-point.

Capture validates all physical participants and all physical X/V, including
nodes outside the render subset. It reads the complete QEPH history/activity,
checks the fixed wall suffix, then applies the old strict prefix staging. Failed
validation never changes the published frame/activity selector. Accepted reads
during a private dynamics attempt observe the accepted slab; an interval record
requires a genuine committed endpoint.

The additive configuration v4 / manifest v2 profile carries three small files:
`environment-wall.mesh.json`, `environment-wall.obj`, `environment-wall.json`.
They serialize the actual declared fixed reference surface, complete source
identities, material and separate friction, and half-thickness/reference-plane
association. They do not invent canonical wall cards or reuse the M2 setup
receipt. Existing record codecs, legacy configurations, manifests and wall files
keep their exact validators. Recovery of an incomplete environment archive is
explicitly unavailable until a matching recovery descriptor is qualified.

Replay uses the existing mesh renderer. Part colors use the actual source PID
and selected palette seed. Automatic framing uses the recorded accepted vehicle
positions only; clipping covers every recorded position and the fixed wall.
No geometry scale, interpolation or synthetic deformation is applied.

`Profile::native_contact == false` excludes the older tiny-scene native-history
observation stream. It does not assert that a future case has no native contact
group. The common case publisher and its separate source/run metadata must
authenticate the actual independent wall and self interfaces.

## Qualification

The owning CMake project builds small field/format gates and the unchanged
global LAW1 mixed-owner field regression. Source-sized invocations are explicit,
never automatic CTests. `CompleteSourceForecastAndExactVehiclePrefix` admits
source/mapping/owner and live output phases under the unchanged 10 GiB guard.
Historical source scratch remains a separately reported maximum; current owner,
capture, writer, reader and test buffers are conservatively charged together.

`ActualCommonOwnerFramesRollbackAndClosedArchiveRoundTrip` reuses the already
qualified complete source fixture, common owner and constrained startup. It
discards one attempt, commits two structural 200 ns steps, writes three actual
accepted frames, closes the archive and checks exact position/plastic/activity
readback plus genuine fixed wall geometry. Contact is disabled in this coupon.
It cannot establish a crash, impact horizon, full native interface readiness,
restart state or performance advantage.

The separate existing `PhysicalSceneArchive` test reads that closed archive,
checks all frame coordinate bits/activity, palette seeds 1/2, wall colors,
vehicle-only camera bounds, complete clipping bounds and failed-seek retention.
No render or simulation is started by source authoring.
