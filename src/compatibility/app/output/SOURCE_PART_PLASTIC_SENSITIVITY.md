The plastic sensitivity tool compares two accepted source-part mesh-wall archives at timesteps h and h/2. It reuses the accepted replay reader, source vector/quaternion comparison, physical configuration comparison and wall event tracker. It reports measured differences; two runs do not establish convergence.

Run `robo_dyna_source_part_plastic_compare H_DIR H2_DIR NEW_JSON`. The destination must be absent. Exit 0 means a complete sensitivity report was written; it does not mean the differences passed a numerical gate. Invalid archives, changed physical inputs or missing common samples return 1 without publishing a report.

Every physical configuration field, native mass/inertia, original source association and placed wall must match. Timestep/output identities and the timestep-derived filter alpha may differ. The accepted reader independently validates the actual source C/P, filter cutoff, alpha, curve, section records and archive identities. This tool accepts adjacent resolutions from the existing source timestep family H = 2^-24 s, H/2 and H/4; it does not impose the earlier elastic pilot's speed, gap, horizon or deformation bounds.

Samples use exact shared physical output cadence, including time zero. Distinct first-step frames and unmatched prefix endpoints are omitted. No interpolation is performed. The planned 131072H horizon with 256H output spacing yields 513 common samples. A valid accepted prefix is reported explicitly with its stop reason and actual endpoint; it never receives a completed-horizon label.

The first four channels report maximum nodal position norm, quaternion rotation distance and synchronized endpoint velocity/angular-velocity differences. Raw midpoint velocities from different resolutions are not compared at the same nominal endpoint time. Plastic channels use corresponding source parent and layer identities: maximum difference over all 282 point plastic strains, maximum over all 94 cumulative parent work values, and total plastic work. Energy, contact potential, carried impulse, reaction and signed energy residual differences remain in physical units. Each channel reports its maximum, time of maximum, RMS over the chosen per-sample statistic, and difference at the last shared time.

Every accepted interval is inspected for its declared energy bound and for contact/separation events. The terminal rebound definition remains the existing 128H strictly-separated run with zero certified force/potential and negative carried COM upper bound. The report also carries final accumulated PLA/work and chord change. Accumulated plastic history is an irreversible material-state observation; neither separation nor a changing chord establishes a stress-free final shape. Elastic vibration may remain. Point plastic work is already represented in generalized native shell work and is never added again to total energy.

Four focused host tests cover physical configuration and derived-alpha separation, common-time alignment, synchronized kinematics and late point identity/data faults with unchanged caller inputs. They do not run another dynamics trajectory. Root execution owns the actual two-bundle qualification and its resource guard.
