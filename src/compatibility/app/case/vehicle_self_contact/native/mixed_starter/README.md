# Mixed Starter source composition

This adapter retains one genuine PostGapmMainSource and builds one owned TL
mixed snapshot. It does not repeat source parsing, support resolution, material
or coefficient arithmetic, physical ownership, or clock construction. The cache
is the actual Starter I25NORM phase; first Engine normals still require authentic
Begin/OPTCD activation. Initial contact history, tied removal and runtime
publication are explicitly outside this handle.

Preflight takes the maximum of the previous construction peak and current live
upstream plus this stage. TL scratch is released before the bounded normal-map
source validation; both are released before the existing chunked field digest.
Only the output arena, immutable upstream handle and small metadata remain.
All failure paths discard the private candidate; no prior source is modified.

The initial implementation depends on the separately owned PostGapmMainSource
API and qualified mixed TL value stage. Source tests and a single complete-context
census must pass before this adapter is admitted to a runtime source factory.

The optional combined-domain overload retains a genuine DomainEmbedding only,
not another physical model. Its original domain must match the retained contact
source and share canonical authority. Original native coordinates are copied
bit-for-bit; the declared disjoint suffix is converted once from actual domain
SI coordinates. Both full node identities and coordinate bits enter the digest.
A count-only TL storage forecast precedes these allocations; exact typed prefix
validation follows real packing. The original sides descriptor is never changed.
Runtime factories must bind domain().SharesStorage(actual physical domain).
