owner, clock, runtime contact source or interface readiness receipt.

from authenticated imported PART/SECTION records, and applies the existing TL

across every controlled incidence. Shared SID/single MID properties propagate

conflicting shared factors return NeedsNativeStorageOrder. Neither case publishes
a coefficient source or falls back to guessed PID/family/EID order.

native property identities are separate from generated SPRING element identities.
