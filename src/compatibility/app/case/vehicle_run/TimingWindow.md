# Interior accepted-boundary timing

`TimingWindow({10,100}, 101, frame_epochs, rows_per_chunk)` measures 90 accepted intervals using the existing steady-clock `Progress.elapsed_s`. Bind `Observe` to `Control.accepted_boundary`; read and serialize `result()` after Execute. The observer must see contiguous boundaries starting at epoch zero. Only a completed window with positive wall duration supplies measured intervals; an early stop leaves an explicitly partial result. A successful window does not establish successful whole-run completion or matching physics.

The optional callback runs at the existing loop-head refresh, after the current accepted interval was committed, appended to the buffered ledger, and sampled if scheduled, before stop/progress checks and the next Prepare. It observes epochs zero through planned_intervals minus one. Default-empty controls retain the existing clock calls, operations and outputs. Observer exceptions use the existing ObserverFailure accepted-prefix path.

The interval `(first_epoch,last_epoch]` includes all normal advancement, force evaluation, publication, accepted diagnostics, buffered interval Append and loop/control overhead. Any enabled progress output is included. The helper rejects scheduled frame saves and ledger chunk flushes in this interval. It permits output at the first boundary because that output completes before the first timestamp. For the proposed 101-step, constant150ns run, use two saved frames at0/101 and verify the actual forecast rows_per_chunk exceeds100. Initial capture, final capture, archive finalization and summary serialization are outside10→100. No profiler sums, asynchronous launch-only timer or new solver loop are used.

Pinned OpenRadioss a62b27e6 placement is different and must be described separately: `engine/source/output/ecrit.F:171` calls ELAPSTIME at ECRIT entry, before current energy/listing output; `:666` prints ETIME with F14.2. `engine/source/system/timer.F:1845` uses OMP_GET_WTIME in the OpenMP build. SORTIE_MAIN calls ECRIT after current force/acceleration evaluation; `engine/source/engine/resol.F:8411` calls SORTIE_MAIN before `:8487` increments NCYCLE and subsequent time/acceleration integration. An ELAPSED100 minus ELAPSED10 interval includes native boundary10 output and subsequent solver cycles up to the boundary100 timer sample, excludes boundary100 output, and has a two-endpoint display-rounding bound of±0.01seconds. It is wall time, never CPU USER time summed over workers.
