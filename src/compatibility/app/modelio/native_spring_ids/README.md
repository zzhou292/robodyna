# Source-owned native SPRING identities

This host source value reproduces the pinned direct Keyword971_R14.1 import's
SPRING identity namespace for retained V5 participants. It is not a native model
loader, solver, material producer or a shipping captured-map lookup. The explicit
profile is Dynakey/SDI PO SortById into a fresh Radioss PO destination; default or
alternate import policies remain unready.

ImportContext is privately constructed from the same authenticated CanonicalSource
and the complete source_files member closure. It checks whole members, every
indexed block hash/keyword/contiguous line span and declared keyword counts. It
reuses existing bounded source-card helpers, default-weld parsing and regular
joint parsing. No boolean can declare an incomplete namespace complete. Source
members with potential spring producers cannot pass through INCLUDE_TRANSFORM
in this first profile; transformed SPRING-free descendants are allowed. Preloaded
Radioss, alternate includes, unsupported element generators and stiffness-joint
variants remain unready. This is a namespace contract, not validation of every
unrelated physical option in the original model.

All original beam records are classified by the actual pinned converter branch.
The admitted material aliases are exact: no arbitrary suffixed family enters by
substring. Existing TYPE13 source handles must bind every actual spring beam;
other beam families are counted but do not affect this destination type pool.
All original ELEMENT_DISCRETE records remain namespace precursors even when their
mechanics are outside V5. One literal-default weld group is processed in source-ID
order, then regular joints in the same broad source-ID selection order across
joint kinds. The allocator computes maximum explicit SPRING ID+1 from these
records and checks the complete generated range before publishing. No starting
ID or expected range is stored in production.

The selected original namespace differs from a hypothetical reimport of a
physically reduced V5 deck. The 35 original discrete rows affect original import
IDs but do not add K, M, nodes or force participants. Original and native IDs stay
separate. Successful Resolution rows are sorted by native ID; physical_order
indexes only retained contributors. source_index means TYPE13 SourceType13 beams,
TYPE25 prepared model connections, and TYPE45 VehicleType45Source rows. Canonical
beam ordinals remain separate provenance. Bindings use source kind/ID/endpoints,
shared canonical authority and actual V5 domain identity. Unready Resolution has
no mapping rows or fallback IDs.

The original canonical wall and the qualification import's amended wall are not
asserted byte-identical. Their complete absence of SPRING producers establishes
namespace equivalence; physical wall equivalence remains another task. The source
factory consumes only authenticated original members and never the native output.

Production links existing source libraries only. The optional actual test alone
loads the sealed 2,872 generated-map and 7,349 native-table records, checking exact
extents/SHA/schema and every identity/endpoint. Its corrupt-byte/extent case writes
only a private temporary copy. Original evidence remains unchanged. The native
expected table is not accepted by any production API.
