# Closed-endpoint witness for an impossible separation search

The optional search extension is deliberately an inconclusive result. If two
validated quadratic facets contain the same exact point at the same closed
endpoint, they cannot be strictly separated for the entire interval. This says
nothing about whether contact is physically allowed or locally incident.

The original input checks, Bernstein construction, real root work increment and
full root `CoordinateSeparated`/arithmetic-validity checks run first. At that
root only, both coordinate intervals must be exact singletons and all three
coordinates must agree. The existing integer-bit `SameFiniteCoordinate` helper
handles signed zero without allowing FTZ/DAZ to equate distinct subnormals.
Cross-time coincidences and overlapping interval enclosures are insufficient.

A witnessed root returns `PotentialContact`, work 1 and depth 0. Every original
candidate, discovery, activity, ownership, coverage, structural screen and final
publication check remains in place. No separation, local intersection, accepted
contact owner or physical receipt is synthesized. Other searches use the original
subdivision order. A private compile-time-disabled comparison path retains the
old search for qualification.

Statuses and actual search-work counters can change: unnecessary later depth,
work or child-arithmetic failures are avoided. This is conservative-outcome
preservation, not bitwise equality of every old inconclusive search report. The
transaction's later physical policy remains decisive; no work is fabricated and
no candidate is removed. Full policy replay and an actual integration comparison
are required before promotion. No vehicle speedup or applicability census has yet
been measured. The combined nonlinear work counter also includes later coverage,
so it must not all be attributed to this one search.
