# Final tied removal for ordinary TYPE25

This allocation-free host value stage consumes the typed pending result of
`BuildGeometricBeforeTied` and the complete finalized TYPE2 roster. Its first
profile is serial TYPE25, no edges, resolved Irem_i2=1, and TYPE2 ILEV28 after
KINCHK/compaction. Both CIN and PEN rows participate; IRUPT is only used to check
the declared CIN census. A source factory must authenticate interface completeness,
storage order, positive retained IRTLM and the finalization phase. These arrays
are numerical inputs, not tokens that grant physical-owner authority.

`PRE_I2` groups master-corner and dependent occurrences by node with stable native
interface/secondary/corner ordering. `REMN_I2OP` visits each target main in order,
suppresses duplicates against its old geometric list, and appends new entries in
reverse discovery order. The rebuilt inverse visits mains in ascending order.
When at least one new pair is added, a literal positive global-main history match
clears exactly IRTLM4, PENE_OLD5 and TIME_S2. Negative markers are not converted to
absolute values. With no additions the original inverse and histories survive.
ICONT_I and every other history channel retain their previous owner/value.

The used prefix ends at the last CSR offset. Native IPARI62/S_REMNODE allocation
may be larger; the input and output retain that extent separately. No padding is
read as a node or copied into the published CSR. Output copies its scalar metadata,
extents, flags, final removals and selected history channels into its own arena.
Every failure preserves output bytes and descriptor. Scratch alone may change.

The independent qualification executes complete pinned PRE_I2, REMN_I2OP,
ZERONM_TAGD, UPGRADE_REMNODE2 and the original MY_ORDERS radix sort. Only private
symbols, allocator/module boundaries and diagnostics are supplied by the wrapper.
No native code links into the production consumer. This does not implement tied
classification, CIN mechanics, runtime deletion, mixed solid topology or a new
physical clock. The matched CIN/contact fixture remains a separate gate.
