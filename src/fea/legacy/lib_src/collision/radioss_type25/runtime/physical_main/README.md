# Physical contact-face incidence

This startup-only validator binds each retained raw contact origin to the actual
immutable physical shell map or original solid source slots. It separately
checks that declared final and pre-shell support EIDs name real incident
physical parents. It does not choose INSOL3D/INCOQ3 winners, calculate contact K,
resolve native storage order, create normals or admit runtime contact.

The index reuses SourceIdentityIndex and the existing native face compactor.
PENTA uses the native raw8 repeated-slot convention. Cyclic/reversed faces are
recognized; crossed Q4 connectivity is rejected. Multiple-origin primaries
retain every source face and have no invented representative EID. A triangular
query may have a real Q4 support without making that Q4 its raw source origin.

Both pre-normal mixed sides and a later mixed Starter snapshot can supply the
incidence view. The owning source producer remains responsible for the exact
post-GAPM phase, ranking, internal count, erosion flag and corner permutation.
The runtime must validate the complete typed topology separately, then join
this physical binding with the actual common publisher. No public mixed runtime
initializer is enabled by this module.

Tests use actual physical QEPH/T3/QBAT and solid references, the qualified mixed
side producer, coincident solid origins, real alternate shell support, PENTA
faces, wrong source IDs, incomplete origins, false representatives, crossed
connectivity, foreign generation and an exact host-cap boundary.
