# Native contact activity source binding

`Plan` owns immutable source identities and incidence. It changes no numerical
operand, mask, parent state, force, contact history, mass, or owner publication.
The runtime must authenticate accepted/prepared activity independently.

`PhysicalSources` requires an explicit TYPE45 model or authenticated no-joint null.
TYPE45 model storage, domain and rigid binding must match the actual physical
source; only endpoints N1/N2 contribute, never axis N3.

The global parent table retains the actual bound QEPH, T3, QBAT, five solid
families, beam18, TYPE25 springs, TYPE13 springs and explicitly bound TYPE45 joints. Node CSR entries have one
ordinal per physical element, even for repeated source slots. Beam and spring
orientation nodes do not participate. Bare element mass, rigid membership and
CIN constraints do not create native TAGOFF support. Only QEPH and T3 removal
are proposed in the first runtime profile; other families require their existing
positive-activity guards. This module does not widen their mechanical domain.

A source producer must prove that this bound physical population is the complete
executed native support population, including elements outside the contact
selection. Coefficient coverage alone does not prove raw-deck completeness.
Omitted source elements that touch contact nodes need an explicit authenticated
resolution; they cannot silently disappear from the support calculation.

Each primary retains every global parent containing **all** distinct main
corners. Expanded opposite/coated sides retain their authentic primary mapping.
These containing parents are separate from the final native IELEM first/second
support pair and the complete raw-origin list. A coincident unselected layer can
support a main; unrelated supporters of individual corners cannot. Mixed face
identity and support validation reuse `runtime/physical_main`; coalesced faces
never receive a fabricated representative element ID.

Controls retain resolved I_DEL, keep-disconnected-node and final solid-erosion
policy. Their raw source provenance belongs to the authenticated application
factory. Existing source checks remain responsible for coefficients, normals,
geometry units and fixed-wall motion. Runtime solid topology and CIN release
remain separate guarded capabilities, even when all solid parents stay active.

The complete node incidence count is exact. Containing-parent allocation uses
an explicit conservative first-corner incidence bound; the published CSR is the
complete exact subset. No candidate or parent is truncated. Preflight accounts
retained handles/arena and simultaneous source-index/count/cursor workspace.
Parent family indices agree with physical batch/source order. Arrays are owned
and remain immutable after initialization. Physical binding handles share their
already-budgeted immutable source storage.

Host qualification reuses complete source producers and tests unselected
coincident support, mixed origins/final supports, node incidence, excluded bare
mass/orientation support, family indices, retry, and exact resource boundaries.
Original native deletion equations and runtime owner publication are qualified
in separate owning modules; this plan is not a native activity receipt.

Deletion emission is a distinct relation. `emitting_offsets` indexes the complete
physical parent table; `emitting_mains` stores ascending one-based registered
expanded main IDs for each QEPH/T3 emitted face. Every registered main must
contain all distinct emitted-face nodes. A T3 deletion can therefore affect a
containing Q4 main, while a Q4 deletion does not necessarily affect a T3 subset.
Opposite sides remain separate registered mains. Repeated triangle corner slots
are idempotent, but different deleted physical owners retain separate events.
The table is indexed by physical family order, not a claim about global native
deletion scheduling. A consumer must preserve native event multiplicity and
qualify its update order. QBAT, solids and other families remain non-emitting
under the first profile's unchanged positive-activity guards.

Emission allocation uses a conservative first-node registered-incidence bound;
the published per-parent CSR is exact. Temporary expanded-main node incidence
and its cursor are charged alongside retained output and existing construction
scratch. No source event is truncated to fit a capacity.
