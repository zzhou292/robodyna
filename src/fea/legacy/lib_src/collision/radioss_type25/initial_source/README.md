# Source-produced initial TYPE25 state

This opt-in producer implements the selected serial Starter phase before the
first Engine interval. It owns no clock, accepted nodal state, material law or
physical publication. `PreparedSource` owns source operands and genuine final
removal tables; `DeviceSeed` owns private GPU histories, flags and finalized
corner gaps. Neither exposes a history setter or physical restart interface.

`Preflight` validates bounded metadata and queries the existing CUB scratch
requirements before source-sized allocations. `PrepareSource` uses the genuine
geometric removal producer followed by ordered finalized TYPE2 augmentation.
It retains the geometric table separately because initial candidates precede
tied augmentation. Its provisional zero history packet is used only to derive
the final CSR; GPU-generated initial histories undergo the literal final reset.
Input arrays are borrowed only until `PrepareSource` returns. Public writable
output objects must be valid and disjoint from all borrowed input ranges.

`Prepare(PreparedSource, owner_stream, DeviceSeed)` copies retained operands to
bounded private device arenas. Whole-source execution uses GPU edge maxima,
BUC grid and post-BUC corner preparation, CUB sorting/scans, complete counted
candidate output, one row writer for nearest-distance/larger-global-main
selection, PWR5, actual tied reset and final local/partition mapping. The source
includes original pre-INITIA raw8 solid incidence, repeated slots, exact
post-GAPM support identity and its second-solid discriminator. No per-pair host
loop or captured state enters production. Final device output is available only
after complete success and stream drain; failed preparation publishes nothing.

The admitted controls are ILEV1, IGAP1, INACTI5, IVIS2=1, ISHARP1/2, IRESP0,
one partition/worker, IEDGE0, no thermal or gap-load cards, FLAGREMN2,
Irem_i2=1, ITHK0, IGSTI4, ISTIF_MSDT0, DRAD/DGAPLOAD0 and the source LVOXEL
8,000,000. BMUL0 preserves the native unsuffixed REAL4 `.20` promoted to double.
Global search GAP is explicitly the earlier I25STI3 GAPS_MX+GAPM_MX result;
post-INI four-corner maxima cannot replace it. The input corners are pre-BUC;
BUC can change corner1 for solid/coated faces. The opaque output owns those
finalized values separately from the immutable input.

Starter inventory has no main-STF sign filter. Positive STF alone controls the
edge metric. Negative and zero main coefficients retain literal source values;
warm counts are reported by sign. Runtime admission of a negative warm main is
a separate continuation contract. This producer never clips K or resets a row
to satisfy an unrelated runtime restriction. TIME_S scratch is not published:
the selected first Begin overwrites it before use. Consumed IRTLM/PENE channels
and initial ICONT are retained exactly.

The source call to I25CAND after PWR/normalization does not mutate these rows.
It is the second routine in pinned `i25pwr3.F:153–205`; it reads IRTLM1 and
MSEGTYP and writes only II_STOK/CAND_N/CAND_E. The subsequent runtime's fresh
inventory contract is separate from this seed producer. Selected Starter
NVSIZ128 follows CONTRL←ARCHINFO(18,1)←GNU/Linux IBUILTIN18; MVSIZ512 is only
array storage. The complete native caller tests cross128-lane boundaries.

## Native population interval

Existing exact-auxiliary-ID profiles are unchanged. The composed-only
`CompleteModelMultiplierTier` profile accepts a complete source-derived native
population interval when its lower bound covers every physical node and both
endpoints select the same original ResolveMultiplier branch. An exact auxiliary
count is explicitly unavailable (`contributors.native_auxiliary_nodes=SIZE_MAX`)
and no auxiliary IDs are supplied. The output retains policy and both bounds;
`native_model_nodes_exact=false` and count0 denote unavailable exact NUMNOD.
Neither endpoint is presented as an exact native count.

The pinned `I25BUC_VOX1` uses NUMNOD for zero scratch extents (TAGNOD and
EDGE_L2_TMP), the declared X extent of margin_reduction, and the INSOL25
first-node bound. `I25TRIVOX1` uses it for zero TAGNOD scratch. Every numerical
visit is an authenticated IRECT/MSR/NSV/tied/raw8-incidence physical node. The
remaining numerical use is the reader's multiplier tier (1,500,000 and
2,500,000 boundaries). No generated/virtual main, secondary or tied node is
admitted. The source binder, not this value producer, proves complete original
and declared-addition generator bounds. Owning tests compare exact and interval
results and reject intervals crossing either threshold.

## Lifetime and resource boundary

Prepared host operands and source identity are immutable. `retained_host_bytes`
includes owned vectors/capacity; `peak_host_bytes` additionally includes the
temporary geometric/tied arenas and validation work. `peak_device_bytes`
includes copied source/operands, sweep, private seed and all simultaneously live
scratch. Case planning must charge both retained interface preparations, both
runtime transactions and one producer peak at a time. General runtime binding
must compare actual source/topology/domain/unit identity and source fields,
authenticate the real owner, initialize both existing history/flag slabs and
final corner fields by D2D copies on its borrowed stream, then drain and retire
the private seed. A fixed source separately supplies its genuine ready-normal
view; the initializer always consumes Starter normals.

The owning oracle compiles complete pinned BUC/INSOL25/TRIVOX/STO/COR3T/PEN3A,
native sorting and PREPARE_INT25, reusing whole COR3/PEN3/PWR3 and original
geometric/tied removal oracles. Source generation is not numerical qualification.
