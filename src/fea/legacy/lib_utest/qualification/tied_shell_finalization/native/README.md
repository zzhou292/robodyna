This independent oracle compiles complete pinned I2TID3, KININI and KINSET.
`source-manifest.json` records the full OpenRadioss revision, SHA256 and Git blob
identities. The LECINT connection-count fragment is extracted exactly; the
complete INTBUF initializer is retained as evidence for the selected phase.

The explicit packet supplies one serial ordinary IS1=2 interface, ILEV28,
IGNORE2, DSEARCH0, IPROJ1, INTTH0, unique NSV, and freshly zeroed connection and
physical-coefficient buffers. Source IRECT, NSV and MSR order is unchanged.
The test context replaces allocation and message services, not finalization
arithmetic. Original KINSET is linked even though ILEV28 skips its calls.
Unused ILEV27 solid-census arrays have dummy storage and cannot be reached.

The packet aliases DMIN to the same first NSN entries of the seven-wide DPARA
buffer as the original caller. Mode 1 labels only the unused suffix to expose
that alias; it does not admit arbitrary physical coefficients. Native MSR
compaction precedes its NMAS loop, so a generic prepopulated M/J permutation is
intentionally outside the value API. IRUPT and physical M/J stay fresh zero.

ANCMSG accumulation, flush and direct calls are captured in call order with
their numeric payloads. Empty flushes are calls, not invented printed warnings.
The temporary interface ID is 71 and ITAB uses packet node indices; the app
maps the validated rows to retained original source identities.

The oracle is serial and owns process-global native context. Bounds-checked
Fortran compilation and runtime are required in the owning gate. It does not
establish classifier state, initialized mechanics coefficients, or runtime
attachment admission.
