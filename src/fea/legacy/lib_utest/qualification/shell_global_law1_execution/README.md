# Global LAW1 execution catalog and mixed owner qualification

Explicit per-parent GlobalLaw1Npt0 policy retains raw shared MID/SID/NIP and
binds the qualified coefficient-thickness/unit profile immutably. Global rows
have ordinary shell histories, zero material points and no elastic/plastic point
accessors. Default section execution, LAW44, layered LAW1, QBAT and rigid roles
remain separate. Raw NIP3 is this first qualified source policy, not a universal
restriction on native global integration.

Catalog tests reuse existing declarations, shared SID and complete failure
source bindings. Optional profile storage is checked at exact caps; all-legacy
collections allocate no profile payload. The small new header pointer and
trailing parent policy are accounted by current sizeof-based preflight.

Mixed-owner tests reuse the existing empty-CIN physical source builder, raw M/J
ledger, real QEPH/T3 mapped batches and common publisher. Six constitutive parents
combine global elastic, layered elastic and plastic roles under one owner. Native
forces/history/STI are checked on that owner's actual trajectory, with separate
native history evolution. These are prescribed-force and publication checks,
not a whole native-dynamics or full-Yaris comparison. Common rejection/discard/
retry preserves accepted state. No alternate clock, copied geometry parser or
manufactured layer history is introduced.

The standalone dispatch coupon poisons inactive point storage and verifies that
global force/initial-STI paths use only the explicit profile and ordinary history.
See INITIAL_STIFFNESS.md for the native virgin-thickness floor phase and unit
boundary; both initial and subsequent force paths share its selector.

Owning configure: this directory, -DGLOBAL_LAW1_EXECUTION_CUDA=ON, existing GNU
Fortran/CUDA toolchains and strict floating-point flags. Execute complete host and
CUDA CTests in separate resource guards. Included regressions cover qualified
global/native/layered force values, mixed execution catalog, mapped source/owner,
empty and legacy CIN, and full physical common publication. No app profile or
vehicle run is changed by this TL slice.
