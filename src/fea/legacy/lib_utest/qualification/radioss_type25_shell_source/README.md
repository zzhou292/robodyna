# Whole-shell startup qualification

`prepare.py` verifies frozen native observation hashes and emits C++ inputs and
expected arrays. Inputs come from the declared physical source mesh, not from
expected output K/gaps. Original native ITAB/NSV identities map the observed
Engine rows back to source nodes. Startup ETNOD, NSHNOD and STIFINT are observed
after actual INITIA; primary/secondary K and secondary gaps come from the actual
capped single-thread reference Engine. Raw MS/J remain evidence for the physical
owner's separate qualification. None of these records are production factories.

The observed scene is uniform; separate heterogeneous analytic tests verify
noncontact contributions, T3 incidence, part/element/property distinctions,
independent main/secondary caps and exact removal masks. Invalid source ordering,
duplicate source/primary IDs, unsupported profiles, overlapping storage and late
arithmetic failures must reject without publishing partially updated output.
CMake and Bazel build production directly without a Fortran or CUDA dependency.
