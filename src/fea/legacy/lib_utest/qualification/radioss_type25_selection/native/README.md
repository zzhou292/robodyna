# Native selection-stage oracle

The first executable boundary is a complete local retained occurrence: original `I25COR3_1` preparation, full `I25DST3_1`, then `I25GLOB_1` cache publication. It consumes a supplied prior-row snapshot. It does not rerun BeginHistory, infer an eligible candidate, or prove whole-cohort repeated-row scheduling. Production classification, bounded phase orchestration and their tests are separate from this reference.

`Sources.py` checks complete donor hashes and copies whole subroutines. Original numerical statements are preserved. A test-only observer copies local DD immediately before the retained classifier returns; it changes no intermediate calculation. Fortran uses the native double constants dependency expressions and native REAL*4 normal/bisector storage. The local C++ adapter packs supplied fields, preserves node/boundary equality and global main identity, and calls no production numerical routine. Local dense indices are only reference-library array addresses, not replacement global tie keys.

The whole source defines FAR, PENT, DD and DIST even for inactive rows. For active rows, raw LB/LC are computed in all four sectors, including T3. Clamped LBP/LCP are defined in sector1 for T3 and all four sectors for Q4. Inactive barycentrics and unused T3 clamped/cache channels are not native numerical observations. Results expose explicit masks and API-defined zero values for those fields. Separate optional scratch observations retain the fixture's finite seed so tests can check preservation and seed independence without fabricating a native result.

After COR preparation, the wrapper checks the actual native activity product before guarding the old-sector array subscript. A would-be undefined active sector returns a wrapper readiness flag and the C++ adapter throws before reading incomplete outputs. The flag is not a donor status or repaired result. Inactive products, including underflow-to-zero, do not consume that subscript. Equal boundary IDs require identical binary32 storage; otherwise a single native reference slot cannot represent the input.

This first boundary admits local IGAP1/INACTI5 with zero selected radiation/gap-load operands. The physical source adapter still must authenticate all fields, activity and complete phase/candidate generations. The foreign module supplies only symbols needed to compile original unreachable branches; its pointers are null and local wrappers cannot select them. Native observation storage is serial qualification-only state and never a production dependency.

`prepare.py --output DIR` emits Constants, LocalBoundary, Observations, CorRetained, DstRetained, GlobRetained and RetainedWrapper sources plus explicit include stubs. Use the same qualified GNU Fortran precision/bounds flags as the other native oracles. `--check` verifies generated bytes. Source generation has passed; compilation and numerical qualification are separate owning gates. Continuation and new-impact wrappers are described below; numerical qualification is separate from source generation.

## Continuation stage

`OracleContinuation` now runs the complete original COR3_21, DST3_21 and GLOB stage for one supplied local occurrence/row snapshot. Normal-reference IDs ADMSR and ISLIDE are not compressed: a bounded reference-only arena supplies their actual integer indices. Its explicit qualification cap is 1,048,576 normal references (28 MiB for LBOUND and float32 bisectors at that cap). This is not a production value-layer capacity or a changed physical roster. Typical 10,003-reference coupons retain about 280 kB. The real supplied NRTM is passed unchanged to DST21, so ETYP>NRTM keeps its original shell/solid/coating meaning.

Observation-only assignments expose the initialized DD, INGAP and common-axis flags, the effective selected IT after zero-penetration rejection, and entry into the original local winner branch. `row_replaced` is never inferred from unequal bytes. A winning private CAND_E=1 assignment is translated back to the supplied local_main only when that branch marker is set; nonwinning raw row fields remain unchanged. Global MSEGLO tie identity is never renumbered. Raw/clamped/cache masks and separate scratch seed observations retain the same meaning as the retained wrapper.

The generator emits CorContinuation.F, DstContinuation.F, GlobContinuation.F and ContinuationWrapper.F90 alongside the retained sources, plus the explicit local-process/task/lock boundaries. Original numerical statements and comparison order are preserved. The native reference remains serial/non-reentrant qualification code; no threaded benchmark or physical publication authority is implied. This completes the continuation scalar source boundary, not the original COMP2 list snapshot, multi-occurrence winner fold, sliding expansion, new-impact stage, or vehicle integration. The next section describes the complete new-impact wrapper added after this continuation boundary.

## New-impact stage

`OracleNewImpact` compiles complete original COR3_22, DST3_22, GLOB22 and all called INTERSECA_25, INTERSECB_25 and INTERSECV0_25 routines. Their numerical operations, literal volume-product predicates, DT1 reconstruction and caller tolerances are not translated by the reference. The supplied previous_dt sets only a serial test-reference DT1 COMMON; this does not advance a physical clock. All retained/continuation/new-impact oracle calls remain non-reentrant.

The reference preserves the actual primary/opposite local indices, global MSEGLO keys, NRTM and signed MSEGTYP. Original COR22 selects the opposite only for positive MSEGTYP, with its native NRTM subtraction. Supplied partner metadata must match that index and the SH2SURF25 node-order permutation; this is packet consistency, not authentication of an external source roster. Primary coefficient/gaps remain primary on a side-B win. Only partner normals, neighbors and bound-reference fields read by COR22 are populated; its unread IRECT/coefficient/gap entries are not fabricated. Unbound corners get private zero-LBOUND references because their index identity is unobserved by this stage; authentic bound IDs and cross-side float32 equality are retained.

Both main and normal-reference tables have a qualification-only cap of 1,048,576 entries, checked before allocation. `NewImpactOracleStorage` reports declared table bytes: `264*main_slots + 28*reference_slots`, including C++ packed tables and explicitly unpacked Fortran tables. At both caps this is 292 MiB, plus small fixed wrapper/source scratch and allocator/compiler overhead; it is not a measured RSS claim or a production memory forecast. Typical synthetic fixtures use small main counts. Larger samples still require the workstation guard and actual RSS evidence.

Observation-only copies expose all raw/clamped projection values and DD, initialized per-side FAR/INGAP/PENA/PENB, native intersection/recontact results and pre-side-choice selectors. Separate hooks record the actual strict primary/opposite branch and global row-winner branch. A local opposite-side choice may change cached main even when the global row does not win. No result is inferred from whether history bytes changed.

All four projection sectors are source-defined even for T3/inactive rows. Generic projection FAR/penetration stay API-zero and mask-clear because those values belong to the separate side arrays. Scalar PENT is source-defined only for active rows; scalar FAR/LBS/LCS only for a strict side winner. Unused scalar storage is fixture-seeded and available separately for preservation checks. GLOB22's cleared cache fields are native-defined, including inactive/equal-side cases. Prior IRTLM1=INT_MIN rejects before the original unrepresentable unary-minus comparison.

The generator adds CorNewImpact.F, DstNewImpact.F, GlobNewImpact.F, the three selected intersection-helper files, NewImpactWrapper.F90 and the explicit clock include. This is a complete one-occurrence scalar source boundary, not candidate-list eligibility, sliding expansion, cohort row reduction, source topology binding, force/history publication, a throughput result or a vehicle acceptance. The eventual composed new-impact→selected raw geometry gate must still close the defined-XP reachability question using these actual producer outputs.
