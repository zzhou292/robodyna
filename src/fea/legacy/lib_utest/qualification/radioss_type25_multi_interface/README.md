# Native multi-interface publication qualification

This numerical protocol fixture binds one/two genuine independently initialized
TYPE25 Transactions to one actual owner/material publisher. Two entries have
unique source IDs, distinct damping/friction laws and different reference
margins. The source is the existing bounded 18-node qualification fixture;
this does not establish a shipping two-interface source deck or native worker
ordering. Production TYPE25 arithmetic/kernels remain unchanged.

The first explicit native-group capacity is two; excess count is a resource
rejection, with count checked before entry reads. Old MappedWall/SelfContact
fields retain the legacy path. Native group mode is exclusive with those fields.
All source/owner/entry validation completes before the first issuer is bound.
Every member is mandatory; destroying one retains its source-ID tombstone.

The new two host groups qualify bounded views/defaults and actual legacy host
forecasts. Eight actual CUDA groups cover complete/capped/aliased admission,
duplicate IDs and foreign scope, pre-write declared order, two independent
accepted histories/reference selectors, malformed/stale receipts, active
second-child/structural/common rejection, sibling cache revocation/retry,
lifetimes and count1 numerical parity. Diagnostics remain descriptive after
discard; private issuer/selector state and authenticated attempt observations
are the authority. Tests intentionally use only common discard before retry.

The owning CMake gate also reuses physical-publication native-state tests,
legacy mapped wall/M2 consumers and the original single-native 1000-interval
reference trajectory with unchanged tolerances. No production callbacks,
contact math replacement, force/state arrays or new per-step allocation are
introduced by the group. All stages publish only after the sole owner commits.

Root owns serialized guarded execution. The source author runs no numerical
job. This seam does not admit mixed surfaces, full vehicle failure/activity,
source-owned finite wall inputs or an additional physical clock.
