# Compact, fully validated QBAT activity

Baseline TL956. Shared packet extraction f0fe2c86 preserves the existing QEPH
layout through aliases. The QBAT source uses the complete unchanged ValidResult
and ValidHistory predicates on every current accepted/prepared parent, on GPU.
The original material construction, curve rebasing and immutable source catalog
are unchanged. Uploaded material is the same source used by candidate/assembly.

Host Parameters lookup remains first at every source parent before its device
failure/invalid-byte verdict. The lowest source index still wins; numerical
failure has the original status/message/index and discards the candidate.
Caller flags and accepted diagnostics publish only after the full successful
scan. All public capacity, owner/token, identity and alias preflights are retained.

Each row is overwritten freshly. Invalid rows have byte 2 and contribute to an
integer atomic minimum. There is no floating-point atomic, reused verdict,
static activity assumption, force/history write or material/timestep change.
The separate device packet is uint32 plus one byte per parent. Host backing uses
BoundedStartupArray with exact extent and its 64-byte control allowance in both
forecasts. Full Snapshot/result staging and validation remain unchanged.

For 4,250 actual four-point parents, traffic per activity accessor becomes 4,254
bytes instead of 13,668,000. This is a transfer count, not a measured speedup.
