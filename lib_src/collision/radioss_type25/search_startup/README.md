# TYPE25 search startup values

This bounded host producer derives search inputs from source mesh and resolved
coefficient/gap values. It owns no physical state, material, accepted step or
clock. The app source factory retains the complete model census, native roster
order, exact source generation and fixed-main/source lifetime authority. A
contact-only census cannot establish the absence of other model contributors.

The first declared profile is ordinary exterior fixed-main Q4/T3, ILEV1, raw
IGAP1, FLAGREMNODE2, INACTI5, IEDGE0, INTTH0, no gap-load cards, one native
partition, and no ties, rigid/CIN or unsupported additional contributors. Unknown
census/load policy is distinct from declared absence. Independent fixed nodal
boundary conditions and initial velocities are allowed. Source units are native;
SI positions use the same explicit UnitScale boundary as the topology producer.

The immutable actual BuildStarter snapshot supplies the expanded main order and
physical-parent identity. Each main's opposite gap must match its source primary
bitwise. Resolved secondary/main gaps determine the original maximum-gap bound;
no captured margins, removal lists or contact flags enter production.

- BUMULT follows STARTER0's machine.inc REAL4 literal0.20 promoted to MYREAL8,
  followed by the original whole-model node-count thresholds. Its scalar leaf
  can qualify thresholds beyond the bounded full-table profile.
- I25BUC_VOX1 uses the complete expanded G=2P mains. It sums the original edge
  lengths and applies margin_reduction exactly for G<=3. The first-largest box,
  first stiffness-masked count, later unmasked counts, REAL4 .001 promotion and
  .75 reduction are retained. Nonfinite arithmetic, exhausted iteration budget,
  or a continuing loop whose mean cannot change reject before publication.
- I7REMNODE_INIT and get_list_remnode perform genuine geometric neighbor
  removal, followed by original I25REMNOR order. This can be nonempty without
  any ties. SerialNative preserves the original worker-local scratch, including
  the no-expansion arm's lack of cleanup. No mixed-row partition-invariance is
  claimed. InvariantNoExpansion instead requires every exact initial native
  min-edge/gap comparison to rule out expansion (or no shared main/secondary
  source nodes); only then are empty arrays a proved result independent of
  preprocessing worker assignment. These policies do not select Engine workers.
- CURV_MAX is the native search bounding length: raw ICURV0 gives zero by source
  branch, and ICURV1 gives half the largest coordinate extent of each primary.
  It is not a differential surface-curvature estimate.
- Original allocation sets ICONT_I to zero and selected INACTI5 PWR3 preserves
  those flags. This does not replace Starter initial penetration/history work.

Preflight reports both aligned output and private scratch, including bounded
removal capacity. Source-order counting precedes capacity admission and output
fill; successful results are never truncated. The second identical serial pass
uses the same initialization and supplies actual rows. Transposition preserves
expanded-main/node-list order and one-based native main IDs. No per-row heap
allocation, sort reordering, dynamic pool or physical publication is involved.
All failure paths preserve output bytes and its descriptor; reported complete
removal counts are distinguished from incomplete work/resource failures.

Moving-main ACTNOR/TAGNOD normal maintenance, changing source/activity, native
initial history binding and additional tie/constraint augmentation remain
separate runtime/source work. Startup value parity is not a complete contact or
whole-step performance qualification.

The ordinary moving-shell Starter profile uses the same initial geometry,
coefficient/gap fields and complete model census as the fixed profile. This
producer admits either explicit Starter profile; its initial margin/removal/
flags do not certify later geometry or replace runtime search maintenance.
