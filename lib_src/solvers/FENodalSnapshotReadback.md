# Accepted and prepared nodal snapshots

`FENodalState::CopyPrepared(token, outputs, &prepared)` gives the case validator
candidate x/v/omega/quaternion and actual reaction force/couple values before its
common owner/shell publication. It uses `NodalSnapshotBuffer`, like
`CopyAccepted`. Position and velocity are required; the four extended fields
remain optional and require an extended owner. Legacy translation x/v readback
is supported. The returned `NodalPreparedView` is the same authenticated view
that `BorrowPrepared` would produce, with the same lifetime and const device
kinematics. It does not grant publication authority or expose mutable reactions.

The owner accepts this operation only after a completed advance, in `Ready` or
`AwaitingValidation`. The latter permits the validator to inspect reactions
before issuing its receipt. The token must identify the actual owner, accepted
base epoch and current attempt. A read does not advance history, validate a
candidate, commit an endpoint or allocate storage.

Candidate x/q belong to `prepared.proposed_time`; v/omega belong to
`prepared.velocity_time` and its explicit velocity phase. Reactions are the
forces and couples generated by that candidate kick, whose base endpoint is
`prepared.base_time` / `prepared.base_kinematics.base_epoch` and duration is
`prepared.kick_dt`. They are copied from the trial slab, never reconstructed
from velocity differences. These fields do not establish native collocated
kinetic energy or label reaction work as dissipation.

The shared `SnapshotRanges` preflight checks active capacity, required fields,
extended-owner compatibility, address overflow, all output pair overlaps and,
for prepared readback, overlap with the input token. Invalid output preflight
does not consume the prepared attempt. Wrong token/phase and numerical readback
failure retain existing owner rejection behavior; the coordinator discards and
retries as appropriate. CUDA failure poisons the owner, as for `CopyAccepted`.

Both paths copy the same complete active slab into existing startup-allocated
private staging. Every scalar, including unrequested fields and any group tail,
must be finite; all nodal quaternions must be unit. Only then do infallible host
copies and the identity assignment publish the result. All caller output bytes
and the input token survive every failure. Accepted state is never modified.
No startup allocation count, node capacity, device/host byte bound, slab selector
or temporal policy changes. Calls and caller buffers must be serialized with
other owner operations; host outputs must not address private owner storage.

Qualification target `nodal_prepared_snapshot_check` is available in the owning
Bazel package and under `TL_NODAL_RIGID_OWNER_CHECKS` in the existing standalone
nodal-rigid CMake project. Its nine CUDA functions cover two-group first/later
reaction parity through commit, accepted-state exclusion and exact rejected
retry, all output/token aliases, stale/wrong/unprepared tokens, null/overflow/
short ranges, legacy x/v-only output, 2048-node final constrained reactions,
late nonfinite reaction and nonunit quaternion rejection, and a linker-injected
CUDA copy error after private staging has completed. The injection is confined
to the qualification executable; production has no test hook. Runtime results
must come from the guarded qualification run, not host syntax checks.
