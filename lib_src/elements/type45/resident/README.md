# TYPE45 physical resident participant

`Batch` retains the immutable three-kind joint model and two complete history/cache slabs. `InitializeJoined` allocates and constructs the independently qualified native TT0, pre-automatic-stiffness cache. It does not advance a material interval or invent a future clock. `InitializePhysicalWithJoints` attaches it as an optional seventh participant only after every common participant and actual owner/source proof succeeds. The existing six-participant initializer remains strict and unchanged in meaning.

The selected `PhysicalAggregateV1` profile obtains the actual owner's authenticated, post-CIN initial main coefficients and configured fixed timestep internally. The first candidate prepares automatic stiffness; it becomes immutable only when the sole common owner commit succeeds. Failed and discarded first attempts leave the accepted TT0 cache uninitialized. The main-node minimum principal inertia is distinct from the model's native mean-principal damping input. This analytical aggregate profile does not claim unwritten native PART main-node fields or full-solver ordering equivalence.

Accepted force, couple and scalar stiffness assembly uses the same owner destinations. Candidate kinematics come from the authenticated prepared view. Histories and references retain the native released DOFs; no joint mass, second coefficient ledger, clock or owner commit is added. All source joint, rigid kind/ID, model, owner, configuration, qualification and claimant associations are checked. Readback stages the complete model-ordered packet and rejects output overlap with participant storage and every retained source authority.

`BatchForecast::startup_host_bytes` is the sum of `retained_model_backing_bytes` and `incremental_host_bytes`. The increment contains Batch/Impl handles, retained readback/context/main staging, and the larger of upload storage or initial owner proof. Those temporary phases do not overlap. There is one device allocation and no interval allocation. A coordinator may discount already shared model backing explicitly; it must still count the full increment.

This slice supplies resident values and common publication. Original case disposition, app startup, loaded contact scheduling and run-duration admission remain their owning modules' contracts. Native signed internal work and actual kick/drift work are reported without a kinetic-energy claim.
