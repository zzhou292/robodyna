`physical.coefficients()->type25()` as its sole model authority. It authenticates
the complete fresh physical ledger against the actual owner's source positions,
raw M/J and CIN roster. Endpoint-only checks require present free rotations and
exclude actual PART/plain rigid membership. CIN dependent inverse M/J may be
zero. Unrelated solid-only nodes may have real zero J and absent rotations.

The first mapped profile admits only zero damping in all four TYPE25 channels.
This covers all original default welds. R6DEF3's pre-floor K values already live
in the existing Evaluation slabs. The R2LEN3 nodal branch returns K when NEW OFF
is positive and zero otherwise. It is independent of current nodal M/J only for
this zero-damping profile. General damping must use its actual native current
coefficient producer before a later mapped profile can admit it.

A newly failed interval retains its native endpoint force/work, while its next
accepted stiffness contribution is zero. The following force evaluation clears
the inactive force through the existing recurrence. No force, failure, work,
frame, timestep or scatter equation is changed. Virgin setup shares the existing
coefficient/cache packing; it does not call interval mechanics with dt=0.

owner token. Connection and endpoint order is preserved. The existing candidate
operation and one accepted/trial slab switch remain common. All rejected trial
contributions are discarded by the sole owner transaction. Legacy joined
initialization and assembly remain separate and reject the mapped path.

The existing `ShellBatchPublication` is the only production publication friend.
Mapped attachment preflight binds the exact physical handle, initial live source
