# Initial physical owner and CIN contributor proof

`shell_physical_owner::ForecastProof` bounds the complete temporary readback:
13*N doubles for x/v/q/omega and 2*N+2*R+1 doubles for raw CIN coefficients and
attachment history. The family includes those exact bytes in its startup cap
before allocating. The helper retains no arrays, roster, time or history.

`AuthenticateInitial` requires the complete prepared coefficient ledger, the
same actual CIN domain backing and complete admitted witness source, and a fresh
staggered collocated owner. It compares every represented source position,
declared rest/common translation and raw M/J. It does not reconstruct source
coefficients from inverse values: CIN dependent and PART zero inverses are
authentic roles. Family startup separately checks its actual mapped DOFs through
the owner's read-only `ValidateFreeRotationalNodes` query when applicable.

`BorrowAssembly` later authenticates the same accepted owner stamp, live token,
assembly pointer identity, phase/attempt/stream and actual CIN destinations. It
does not compare post-transfer current coefficients against initial M/J. The
caller remains responsible for its native force/stiffness values and complete
activity declaration. This helper grants no participant claim or commit.

`ShellPhysicalOutputRanges` protects the complete retained shell physical
scope, including domains retained by semantically equal but independently
allocated producers. It changes no source payload and uses no semantic equality
for a storage-sharing discount.

The CMake values target contains only forecast/range checks. The runtime target
adds the live owner readback/borrow calls and links the existing nodal owner.
No material/formulation execution role is inferred by these helpers.
